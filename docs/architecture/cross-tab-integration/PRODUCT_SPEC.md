# 产品规范：全局工作篮与跨 Tab 联动

## 1. 名词

- **剪贴板（Clipboard）**：系统复制历史。管理文本/图片/文件/链接的采集、去重、分组、
  粘贴回目标应用。数据由 `clipboard_items` 维护。
- **工作篮（Transfer Tray）**：用户主动收集的、**当前这一批**要处理的内容。它可以包含
  剪贴板条目、文件引用、文本、链接、任务/项目/规划/知识/采集实体引用。数据由
  `transfer_items` 维护。
- **暂存架（Shelf）**：长期暂存与归档（文件托管、标签、分组、清理规则）。工作篮与它
  互相投递，但不共享存储。
- **目标（Target）**：一次发送的接收方，可能是目录（文件工作区）、任务、项目、规划条目、
  知识库或采集收件箱。
- **批次（Batch）**：一次批量发送的执行记录，含逐条结果、进度、重试与撤销信息。

## 2. 为什么工作篮不是「剪贴板历史第二页」

| 维度 | 剪贴板 | 工作篮 |
|---|---|---|
| 产生方式 | 系统自动采集 | 用户显式加入 |
| 内容范围 | 只能来自复制 | 任意模块的内容/引用 |
| 生命周期 | 按保留策略自动清理 | 用户处理完才离开（临时项可配置过期） |
| 目标 | 粘回其他应用 | 发送到 TaskDock 内部模块 |
| 去重 | 按内容哈希合并复制次数 | 按来源+内容去重，但**发送后可再次加入** |
| 失败处理 | 无「批次」概念 | 逐条结果、部分成功、重试、撤销 |

工作篮的「剪贴板」页签只是**选择器**：列出剪贴板历史供勾选，勾选后调用
`clipboard → tray` 的引用写入。它不维护第二份剪贴板历史，也不监听系统剪贴板。

## 3. 工作篮的收集规则

### 3.1 可加入的类型

| 类型 | 来源 | 存储方式 |
|---|---|---|
| `text` | 剪贴板文本、手动输入、收集箱文本 | 内联 ≤64KB；超出入 `transfer_contents` |
| `richtext` | 剪贴板 HTML | 内联 HTML（≤64KB），发送时导出 `.html` |
| `image` | 剪贴板图片 | `payload.clipboardItemId` + 尺寸，不存字节 |
| `file` | 文件工作区选中项、拖入、剪贴板文件 | `payload.path` 绝对路径引用 |
| `directory` | 文件工作区选中目录 | `payload.path` |
| `url` | 剪贴板链接、文本中的 URL | `content` 存 URL |
| `clipboard` | 剪贴板条目（保留原始类型） | `payload.clipboardItemId` |
| `task` / `project` / `planning` / `knowledge` / `capture` | 各模块实体引用 | `sourceId` + 展示快照（标题/副标题） |

### 3.2 去重

- 稳定键 = `type + sourceModule + sourceId`（有稳定 id 时）；
- 无稳定 id 时 = `type + sha256(内容/路径规范化) + 字节数`；
- 仅对**未发送**状态（`ready` / `failed` / `expired`）做唯一约束；
- 重复加入时返回已存在条目并在 UI 提示「已在工作篮」，不静默丢弃。

### 3.3 生命周期

```
ready ──发送中──> sending ──成功──> sent（保留 N 天可追溯）
  │                  └──失败──> failed（可重试）
  ├── 引用失效（剪贴板清理/文件删除）──> expired（保留，提示重新收集）
  └── 临时项超期（可配置，默认关闭）──> expired
```

- **固定（pinned）条目永不被自动清理**；
- 发送成功后条目默认保留 7 天（可配置），仅用于「刚发过什么」追溯；
- 用户手动删除是唯一立即消失的路径，删除支持撤销（恢复原记录）。

## 4. 发送到「文件工作区」

### 4.1 文本

- 单条：保存为 `.txt` 或 `.md`（用户选择）；
- 多条：合并为一个文件（默认，分隔线 `\n\n---\n\n`）或每条单独文件；
- 文件名：自动建议（首行前 40 字，清洗非法字符）或用户自定义；
- Markdown 模式下，纯文本按原样写入；不自动加标题层级（避免篡改用户内容）。

### 4.2 图片

- 以 PNG 写入（剪贴板存储格式），保留原始尺寸；
- 文件名默认 `剪贴板图片-<序号>.png`，可改；
- 剪贴板缓存已被清理时，该条标记 `expired`，不阻塞其余条目（部分成功）。

### 4.3 文件 / 目录

- 默认**复制**，可选**移动**（移动必须二次确认）；
- 同名冲突策略：跳过 / 重命名（`名称 (2).ext`）/ 覆盖；
- 跨磁盘移动、占用、权限不足、磁盘满由 `fsops` 逐条报告，不中断整批。

### 4.4 链接

- 生成 `.url` 文件（Windows 快捷方式格式）或 `.md` 内的 Markdown 链接（可批量合并）；
- 批量时默认每链接一个 `.url`，可选合并为一个 `.md`。

### 4.5 混合内容

执行前必须展示预览：

- 各类数量（文本/图片/文件/链接/不支持）；
- 预计生成文件数；
- 目标目录（绝对路径）与有效性；
- 同名冲突数量；
- 不支持的内容及原因；
- 若是移动操作，明确列出源路径将被移除。

## 5. 发送到其他模块（动作清单）

| 目标 | 行为 | 关系类型 | 是否可撤销 |
|---|---|---|---|
| 创建任务 | 每条文本/链接生成一个任务（标题=首行，描述=来源） | `derived` | 删除任务（显式确认） |
| 添加到已有任务 | 建立引用/附件 | `attachment` / `reference` | 解除关联 |
| 关联到项目 | 项目资料引用 | `reference` | 解除关联 |
| 发送到规划中心 | 关联到规划功能条目 | `reference` | 解除关联 |
| 添加到知识库 | 文本建文档；文件走导入 | 知识库自有 link | 删除文档（确认） |
| 加入暂存架 | 复用 shelf ingest | 无（独立存储） | 从暂存架删除 |
| 创建采集 | 写入收集箱 | 无 | 删除采集 |
| 复制到剪贴板 | 文本/图片/文件写回系统剪贴板 | 无 | 不需要 |

**规则**：默认建立引用，不复制文件；移动/复制必须由用户显式选择。

## 6. 交互入口

1. 工作篮面板（右侧）：标题栏按钮 + `Ctrl+Shift+B` 呼出/隐藏；
2. 剪贴板页多选工具栏「加入工作篮」；
3. 文件工作区工具栏「加入工作篮」「设为发送目标」；
4. 任意条目右键「发送到…」（`SendToMenu`）；
5. 拖拽（P1，见 UI_SPEC §6）。

## 7. 失败与反馈

- 批量操作必须有**逐条结果**；只要有一条成功就不能显示「全部失败」；
- 失败条目保留在工作篮，状态 `failed`，带稳定错误码与可读原因；
- 「重试失败项」只重跑失败条目，不重复已成功条目；
- 不可撤销的操作（移动、删除、覆盖）必须在确认框中写明；
- 任何「成功」提示只在服务返回成功结果后出现，不用事件广播代替结果。
