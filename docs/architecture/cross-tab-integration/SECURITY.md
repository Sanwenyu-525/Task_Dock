# 安全与数据保护

## 1. 文件写入边界（最高优先级）

工作篮从不自己拼接路径、从不自己校验目录。所有写入/复制/移动都经过：

1. `file_workspace::validate_abs_path`：拒绝空路径、控制字符、设备路径、相对路径；
   词法规范化 `..`；
2. `file_workspace::validate_dir`：目录必须存在且是目录；
3. **禁止目标**：
   - 盘符根 / UNC 根（`is_root_path` 语义）；
   - 应用数据目录（`TASK_DOCK_DATA_DIR` / `app_data_dir`）及其子目录；
   - 目标目录与源目录相同（移动时）；
4. `file_workspace::sanitize_name`：文件名不得含 `\ / : * ? " < > |`、不得为 `.`/`..`、
   不得以点或空格结尾、不得是 Windows 保留名；
5. 覆盖写：同目录临时文件 + `rename` 原子替换；失败不破坏原文件；
6. 图片导出：复用 `clipboard::export::save_png_bytes` 的语义（非空、PNG 扩展、原子写）。

**明确不做的事**：

- 不删除源文件，除非用户选择「移动」并在确认框二次确认；
- 不写入符号链接指向的目标之外的位置（`file_workspace::real_path` 会解析重解析点）；
- 不因为「内容来自工作篮」而跳过任何既有检查。

## 2. 路径穿越与权限

| 攻击面 | 防护 |
|---|---|
| `..\..\Windows` | `validate_abs_path` 词法规范化后再判断 |
| 设备路径 `\\.\` / `\\??\` | 直接拒绝 |
| 超长路径 / 控制字符 | 直接拒绝 |
| 目标在保护区 | 与 `protected_dirs` 比较（大小写不敏感、按路径边界） |
| 目录被 junction 重定向 | `real_path` 解析后比较 |
| 无权限目录 | `fsops` 逐条 `FS_OP_ACCESS_DENIED`，不重试、不静默跳过 |

## 3. 数据最小化

- 工作篮**不存**图片字节、不存文件内容副本；只存引用；
- 文本内联上限 64KB，超出走独立正文表（上限 512KB），再超出拒绝并提示另存为文件；
- 错误信息不回显完整路径（列表/事件只带文件名或展示名）；完整路径只在
  `transfer_batch_get` 的 `entries[].target` 中按需返回（用户自己选择的目录）；
- 诊断日志只记类型、数量、耗时、错误码；**不记**正文、文件名、完整路径、剪贴板内容；
- 上下文（当前目录/项目/任务）只存在内存与设置键中，不写诊断。

## 4. 剪贴板联动的边界

- 不新增系统剪贴板监听；只读既有 `clipboard_items`；
- 图片按 `clipboardItemId` 取缓存路径，缓存被清理后条目变 `expired`，不尝试从系统剪贴板
  重新采集（避免在用户不知情时读取当前剪贴板）；
- 「复制回剪贴板」走既有 `clipboard_copy_*` 命令（含用户新复制保护逻辑）。

## 5. 实体关联的完整性

- 关联写入前校验两端实体存在（任务/项目/规划/知识/采集按各自表查询）；
- 删除实体时不级联删除其他模块的关联记录（弱引用），读取时标记 `stale`；
- `parent` 关系限制方向，禁止形成环（校验 source 不能是 target 的祖先）；
- 重复关联幂等，不产生重复行。

## 6. 多窗口与并发

- 所有写入走 Rust 单一写连接（SQLite 串行化）；
- 批次执行由 fsops 调度器排队（2 worker / 32 待执行），前端不做无界并发；
- 上下文与面板状态通过设置事件广播（带单调 revision），倒序事件被丢弃；
- 同一批次重复点击「重试」由前端禁用按钮 + 后端批次状态双重拦截。

## 7. 不可撤销操作清单（必须在 UI 明确告知）

| 操作 | 原因 |
|---|---|
| 移动文件 | 源文件已不存在于原位置；撤销需要反向移动，目标可能已变化 |
| 覆盖同名文件 | 原内容被替换，无法恢复（除非用户有备份） |
| 永久删除 | 不进回收站 |
| 删除任务/知识文档 | 实体删除，关联只剩 stale 记录 |

可撤销（走回收站，用户仍可从系统回收站恢复）：工作篮生成的文件、复制的文件、
工作篮条目删除（应用内撤销，保留 30 秒）。

## 8. 迁移与备份安全

- 迁移 79 只新增表；失败整体回滚；
- 新表登记 `BACKUP_TABLES`（否则 schema 覆盖测试失败，构建被阻止）；
- 备份不导出 `transfer_items.content` 之外的任何文件内容；`payload_json` 中的路径属于
  用户本地信息，与既有 `shelf_items.original_path` 同口径（明文，仅本机）；
- 恢复旧备份时新表为空，不视为损坏。
