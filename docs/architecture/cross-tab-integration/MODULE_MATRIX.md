# 模块接入矩阵

状态口径（2026-11-19 复核后）：

- **已接入**：真实页面入口 + 真实服务调用 + 本轮实际执行过的测试/构建证据；
- **部分接入**：入口已存在，但只覆盖部分类型或只完成单向链路；
- **底层就绪**：数据模型 / IPC / 既有 API 可用，页面内还没有入口，不能当功能交付；
- **未开始**：只有设计。

> 本表以实际代码与执行结果为准；「文档里写了」不等于「已接入」。

## 11. 不变量（architecture invariants）

1. 新增 Tab 只改自己的适配器与矩阵表，不改其他 Tab；
2. 不存在第二套文件复制/移动/删除实现（全部走 `fsops` / `file_workspace`）；
3. 不存在第二套剪贴板监听（只用 `clipboard_*` 查询）；
4. 事件订阅有作用域，页面卸载全部释放；
5. 新表有迁移号与备份登记；
6. 所有写操作返回真实结果，事件只用于刷新。
