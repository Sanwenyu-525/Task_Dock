# UI 规范：全局工作篮面板与跨模块入口

## 1. 为什么面板挂在两个窗口、形态不同

| 窗口 | 默认尺寸 | 面板形态 |
|---|---|---|
| `workspace`（大型工作台） | 1200×760，最小 960×600 | 空间充足时**右侧固定列**（可拖宽）；窄窗或已有上下文栏时**右侧抽屉** |
| `main`（完整面板） | 400×560 | 始终**抽屉覆盖**（窗口宽度不足以再分一列） |

两个窗口共享同一份数据（Rust 后端）与同一份面板偏好（设置键 `transfer_tray_state`），
因此无论从哪个窗口打开，看到的是同一个工作篮。

## 2. 面板结构（固定列形态）

```
┌─────────────────────────────────────────────┐
│ 工作篮            [目标: D:\work]  📌  ⤢  ⋯ │  ← 40px 高标题行
│ 12 项 · 8 待发送                            │
├─────────────────────────────────────────────┤
│ [ 工作篮 ] [ 剪贴板 ]                        │  ← 页签，等宽
│ 🔍 搜索内容…                                 │
│ 类型: 全部 ▾   来源: 全部 ▾   仅固定 ▾       │
├─────────────────────────────────────────────┤
│ ☑ 文本   第一行摘要…          来自剪贴板  📌 │
│ ☐ 图片   1920×1080 · 2.1 MB   2 分钟前      │
│ ☐ 文件   report.pdf · 340 KB  来自文件工作区 │
│ …（虚拟滚动/分页，每页 80）                  │
├─────────────────────────────────────────────┤
│ 已选 3 项 · 预计 3 个文件                    │
│ [ 发送到当前目标 ]  [ 更多 ▾ ]  [ 清空 ]     │
└─────────────────────────────────────────────┘
```

- 标题行左侧：标题 + 条目计数；中间：当前目标 chip（点击可换目标/取消目标）；
- 右侧按钮：固定、收起、更多（更多含「清空临时项」「全部移除」「设置」）；
- 底部：选中统计 + 预计产物 + 主按钮 + 批量菜单；
- 传输中：底部替换为进度条（`已处理 3/8 · 失败 1`）+「取消」+「查看失败」。

## 3. 交互规范

### 3.1 打开/关闭

- 工具栏按钮（主窗口标题栏 / 工作台顶栏）切换；
- `Ctrl+Shift+B` 在任意页面切换（输入框内不拦截，避免抢键）；
- 关闭不丢内容；再打开保持滚动位置与选中项（组件保活，不重建）；
- 固定（pin）：工作台内变成常驻列；主窗口固定仅记录偏好，形态仍是抽屉。

### 3.2 宽度

- 固定列：默认 320，范围 **260–520**；拖拽实时生效，松手后写入设置；
- 抽屉：默认 360，最宽 = `min(520, 窗口宽度 - 48)`；
- 键盘可调：聚焦分隔条后 `←/→` 每次 16px（复用工作台既有 resizer 语义）。

### 3.3 选择

- 单击行：选中/取消（`Shift` 连选、`Ctrl` 点选为 P1）；
- 全选/反选：`Ctrl+A`（面板聚焦时）与「全选」菜单项；
- 固定条目可被选中发送，但「清空临时项」不会删除它们。

### 3.4 排序

- 固定条目置顶；同组内按 `sort_order`；
- 拖拽排序：按住行首握把，插入位置以 2px 指示线提示；松手后把新顺序写回
  （`transfer_reorder_items`），失败则恢复原顺序并提示。

### 3.5 预览与发送

- 「发送到当前目标」→ 先 `transfer_preview` → 展示 `TransferPreviewDialog`：
  - 顶部分类计数（文本/图片/文件/链接/不支持）；
  - 目标目录（绝对路径）+ 有效性；
  - 同名冲突列表 + 解决方式（跳过/重命名/覆盖，默认重命名）；
  - 文本保存格式（TXT/Markdown）、合并或分开；
  - 文件操作（复制/移动，默认复制；移动需二次确认）；
  - 不可撤销提示（移动/覆盖）；
- 确认后执行；对话框关闭但批次继续，底部进度条可见；
- 完成后提示「成功 N，失败 M」并提供「查看失败」「重试失败项」「撤销」。

### 3.6 剪贴板页签

- 顶部：搜索 + 类型筛选 + 来源筛选（复用现有 `clipboard_sources`）；
- 列表：懒加载（每页 60，滚动补页），图片用缩略图 `clipboard_thumb`，失效条目仍显示但不允许加入；
- 多选后「加入工作篮（N）」；加入结果就地提示「已加入 3 条，1 条已存在」；
- **不在此处删除剪贴板**：删除仍在剪贴板页完成（避免两个删除入口语义不一致）。

### 3.7 无障碍

- 面板 `role="complementary"` + `aria-label`；
- 列表为 `role="listbox"` + `aria-multiselectable`，行 `role="option"` + `aria-selected`；
- 所有图标按钮有 `aria-label`，提示统一 `data-tip`（不用原生 `title`）；
- 抽屉打开时焦点进入面板，`Escape` 关闭并归还焦点（走 `overlayStack`）；
- 传输进度用 `role="status"` + `aria-live="polite"`，失败用 `role="alert"`。

## 4. 统一「发送到…」菜单

组件 `SendToMenu`（下拉形态）与 `ContextActionMenu`（右键形态，基于 `PointerMenu`）
共用同一份动作列表：

```
加入工作篮
发送到文件工作区…        （需要当前目录或选择目录）
创建任务
添加到已有任务…
关联到项目…
发送到规划中心…
添加到知识库…
复制到剪贴板
打开原始位置
查看关联对象
```

- 条目按 `supportedItemTypes` / `sourceModules` / 上下文动态过滤；
- 不可用项**保留但置灰**并给出原因（如「未打开文件工作区」），避免菜单项忽隐忽现；
- 危险动作（移动、覆盖、删除）必须 `confirmation: "dangerous"`，菜单项带危险色；
- 菜单宽度 240–320，超长标题省略；不使用固定坐标计算，全部走 `Popover/PointerMenu`
  的定位核心。

## 5. 目标选择器（TargetPicker）

- 目录：列出最近目录（`shelf_recent_dirs` 已有数据）+ 当前工作区目录 + 「选择其他目录…」；
- 任务：最近任务（复用 `list_tasks` 前 20 条）+ 搜索；
- 项目：`workspaceProjectList`；
- 规划：当前项目的功能列表（`planningListFeatures`）；
- 知识库：`capabilityKbList`；
- 选择器只返回 `TransferTarget`，不直接执行；执行仍走 `executeTransfer`。

## 6. 拖拽协议（P1）

- 载荷 MIME：`application/x-taskdock-transfer`，内容：
  `{"itemIds":["..."],"types":["text","file"],"source":"clipboard|files|tray|knowledge|capture","effect":"copy|move|reference|link"}`；
- 投放目标必须调用 `validateDropTarget(payload, target)` 返回 `{ ok, reason }`；
- 有效区域显示 1px 强调色描边 + 半透明底色；无效区域显示禁用图标 + 原因 tooltip；
- 拖拽取消（`dragend` 无 drop）不发任何请求；
- 拖拽阴影与 tooltip 由现有 `TooltipLayer` 渲染，**不**自建 portal，避免被窗口边界裁切；
- 跨窗口拖拽不在本期范围：目标窗口不同时，退化为菜单/按钮入口。

## 7. 响应式

| 条件 | 形态 |
|---|---|
| 工作台宽度 ≥ 1080 且上下文栏隐藏 | 固定列 320px |
| 工作台宽度 960–1080 或上下文栏可见 | 抽屉（覆盖内容右侧，带遮罩） |
| 工作台宽度 < 960 | 抽屉全高，宽度 = min(360, 宽度−32) |
| 主窗口任意尺寸 | 抽屉全高 |

固定列出现时，内容区最小宽度不得低于 420px：若 `窗口宽度 − 导航宽 − 面板宽 < 420`，
自动降级为抽屉（由 `resolvePanelMode` 纯函数决定，单测覆盖）。
