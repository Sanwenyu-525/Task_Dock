# 项目中枢：功能矩阵

> 版本：2026-11-18 设计基线
> 状态口径：
> - `已有`：现有代码可用，本轮不改语义；
> - `迁移`：现有实现保留，但归属/入口/读模型改为项目中枢；
> - `本轮设计`：本轮只出设计与领域逻辑，未落库、未接 UI；
> - `新增（待实施）`：后续阶段实现；
> - `不做`：明确不在本阶段范围。
> 优先级：P0 必须完成；P1 原则上完成；P2 架构预留或评估。
