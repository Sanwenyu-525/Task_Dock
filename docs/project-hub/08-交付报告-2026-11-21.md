### 2.2 关键调用链

**创建（幂等 + 功能落库）**

```
ProjectHubPanel.confirmDraft
  → requestSignature(payload)                      # 只含影响写入结果的字段
  → resolveRequestId(state, signature, createRequestId)   # 同签名复用 ID
  → bridge.projectHubCreateProject(input)
  → Rust create_project
      → clean_create(&input)                      # 规范化（trim/枚举/日期/路径）
      → request_digest(&clean)                    # SHA-256
      → 事务内：查 project_events(clientRequestId)
           ├─ 同摘要 → load_snapshot（返回原项目）
           └─ 不同摘要 → Err(Conflict)
      → insert_project_root_tx（项目 + 初始计划）
      → 写 project_goals / planning_milestones(phase|milestone)
      → 写 planning_features（milestone_id = 真实 phase_id）
      → 写 tasks + task_plan_links + workspace_task_links
      → 写 project_events（payload_json 带 requestDigest）
```

**归档 / 激活 / 删除（不变量）**

```
planning_archive_project → archive_project_impl → archive_plan_tx
  ├─ 归档非当前计划        → 直接置 archived
  ├─ 归档当前计划          → 找同项目未归档继任者
  │    ├─ 有 → 同事务：清 is_active → 置继任 is_active → 更新 active_plan_id → 置 archived
  │    └─ 无 → Err(Conflict)
  └─ 恢复（archived=false）→ 只清标记，不自动激活

activate_plan → activate_plan_tx
  ├─ 计划已 archived → Err(Conflict)（「请先恢复该计划」）
  └─ 否则：同事务切换 is_active + active_plan_id

delete_plan → delete_plan_tx
  └─ 当前计划 → 只从未归档计划选继任者；无继任者 → Err(Conflict)
```

**能力 ↔ 资源**

```
ProjectHubPanel → ResourceView
  → project_hub_resource_candidates(projectId, kind)   # 只列作用域内真实资源
  → project_hub_resource_link(projectId, {capabilityId, resourceKind, resourceId})
      → 能力必须属于本项目（否则 Forbidden）
      → 资源必须存在且在作用域内（否则 Validation）
      → INSERT ... ON CONFLICT DO UPDATE（幂等）
  → project_hub_resource_validate(linkId)              # 重新探测 + 写 last_checked_at
  → project_hub_resource_unlink(linkId)                # 只删关联
```

## 5. 行为变更（用户可见）

1. **归档当前计划会被拒绝**：除非同项目存在未归档的继任计划；错误文案提示「请先新建或恢复一个计划」。
2. **归档计划不能直接激活**：需先显式恢复（`archived=false`）。
3. **同一请求 ID 携带不同参数会返回冲突**（`操作冲突`），而不是静默返回旧项目。
4. 旧命令 `planning_archive_project` 行为随之收紧；`planning_delete_project` 语义不变（只删计划，
   项目根保留）。
