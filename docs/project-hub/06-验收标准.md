# 项目中枢：验收标准

> 版本：2026-11-18 设计基线
> 口径：`通过` = 代码 + 真实执行证据齐全；`部分通过` = 有实现但存在明确未验证边界；
> `不通过` = 未实现或行为错误；`证据不足` = 无法复现或缺少证据。
> 环境阻塞单列 `ENVIRONMENT BLOCKED`，不得计为通过，也不得臆断为代码缺陷。

## 1. 验收前置条件

1. 数据迁移 v78 在**真实旧库副本**上回放成功，行数/外键/唯一索引全部通过。
2. 完整备份与快速备份**真实往返**（导出→清空→恢复→比对），新表行数一致。
3. 既有前端测试基线不回退：本轮基线为仓库当前状态（含既有失败），新增改动不得增加失败
   （新增失败文件必须在报告中列出并与基线对齐）。
4. 既有命令签名不变；`planning_*` / `workspace_*` / `tasks` 回归通过。
5. 五种 kind 各自有真实数据与页面入口，不以 mock 夹具代替后端结果。
