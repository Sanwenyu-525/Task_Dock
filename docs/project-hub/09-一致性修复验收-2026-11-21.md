## 2. 关键修改

### 2.1 数据模型（v87）

`capability_resource_links` 重建为带 `project_id` + `scope` 的表：

- `scope='project'`：仅归属项目可见、可校验、可解除；
- `scope='global'`：显式共享，跨项目一条，所有需要该能力的项目可见/可校验，解除仅创建者；
- 迁移把历史行按 `project_capability_requirements` 展开到各项目；无项目需求的行保留为显式全局，
  不删除、不冒充私有。

`project_hub/schema.rs::MIGRATION_87`，登记于 `db/mod.rs`。

### 2.2 计划生命周期

`delete_plan_tx` 在同一事务内：收集阶段/里程碑 → 补登任务到 `workspace_task_links` →
删除计划级 `task_plan_links` → 删除 `plan_dependencies` → 清空能力需求/交付物的 `phase_id`
（实体保留）→ 切换 `active_plan_id` → 写 `project_events(plan_deleted)`。

`load_tasks(project_id, plan_id)`：阶段/里程碑只在属于 **active 计划** 时才回填，
旧计划任务保留但阶段为空。`integrity_in_conn` 新增任务/交付物/能力需求阶段引用、
计划依赖、计划版本归属检查；跨项目引用 = blocking，指向已删除/非当前计划 = warning。

### 2.3 Agent 操作

与并行任务合并后的最终实现：进程级共享租约调度（`start_runtime(db, sweep)`，15s tick）、
`interrupt_stale` 的 UPDATE 重新校验租约、REST 宽限期耗尽/超时显式 `interrupted`
（`REST_GRACE_EXHAUSTED` / `REQUEST_TIMEOUT`）、`rest_target_id` 正确提取子动作路径 ID、
首次同步并集「全部 running + 最近一页终态」。
`agent_operations` 登记为 `cache/none` + 本地瞬时表：不进入备份、恢复时忽略。

### 2.4 前端

- `ProjectHubPanel`「目标与规划」增加「概览 / 编辑阶段与功能」，编辑态内嵌 `PlanningWorkspace`
  （复用组件、Store、桥接，不新建 CRUD）；旧入口「在规划中心打开」保留。
- `createPayload.ts` 成为草案→请求唯一转换点；未分配阶段 `null`；能力需求带 `phaseIndex`；
  创建对话框明确列出**不会保存**的字段（约束/风险/不确定项/工作空间建议）。
- `buildPhaseSummaries` 与 `calculatePhaseProgress` 统一为「功能完成 + 交付物验收」，
  回退规则与空分母口径一致。
- 能力中心移除 Agent 资源 Tab，保留迁移说明与跳转；Agent 页面新增「接入与授权」，
  复用 `AgentAccessSection`，并用 `:is(.capability-panel, .agent-access)` 复用基础样式。
