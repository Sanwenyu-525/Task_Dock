# 知识与 AI 能力中心：验收标准

> 验收原则：只认真实业务链路与可复现证据；页面出现不算通过；旧功能退化不算通过。
> 结论口径：通过 / 部分通过 / 不通过 / 证据不足；环境阻塞单列 `ENVIRONMENT BLOCKED`。

## 2. 知识库

| 编号 | 用例 | 步骤 | 通过标准 |
|---|---|---|---|
| K-A01 | 创建知识库 | 能力中心 → 知识库 → 新建（名称/描述/类型/项目） | 列表出现；重启后仍在；统计 +1 |
| K-A02 | 编辑与收藏 | 修改名称/描述、切换收藏 | 列表排序与详情一致 |
| K-A03 | 引用模式导入文件 | 选择绝对路径 md/txt，mode=reference | 文档状态 `indexed`；原文件未被复制；删除文档后原文件仍存在 |
| K-A04 | 导入模式导入文件 | mode=imported | 副本位于 `<data>/knowledge/<kb>`；删除文档后副本删除、原文件保留 |
| K-A05 | 文件夹导入 | 选择含文本与不支持格式的目录 | 返回 imported/skipped 明细；不支持格式不显示为成功 |
| K-A06 | 笔记/收集箱/文本导入 | 从笔记、采集箱、手动文本各导入一次 | 内容与来源正确；原笔记/采集项不被修改 |
| K-A07 | 不支持格式 | 导入 pdf/docx | 明确错误「暂不支持」；文档列表不出现假成功记录 |
| K-A08 | 检索 | 中文与英文关键词，按知识库/来源筛选 | 命中文档与摘要正确；结果带文档 id 与分块偏移 |
| K-A09 | 修改原文件后重建 | 引用模式修改原文件 → 重建索引 → 搜索新词 | 新词命中；旧索引被替换；状态仍 `indexed` |
| K-A10 | 索引失败与重试 | 构造不可读文件 | 文档 `failed` + 可读原因；重试后状态正确 |
| K-A11 | 删除知识库 | 删除含引用/导入文档的库 | 文档/分块/关联删除；引用原文件与导入来源原文件均存在 |
| K-A12 | 知识关联 | 关联任务/项目/笔记/会话/文件 | 文档详情显示关联；反向查询返回文档 |
| K-A13 | 授权隔离 | Agent 无 `knowledge.read` 调用知识工具 | 明确拒绝；授权后可检索 |
| K-A14 | 全局搜索 | 全局搜索输入知识关键词 | 出现「知识」分组并可定位 |

## 8. 证据要求

每个通过项必须有：命令 + 工作目录 + 退出码 + 时间 + 证据路径（日志/截图/测试输出）。未执行项写「未执行」，环境阻塞写 `ENVIRONMENT BLOCKED`，不得用「应该/理论上」代替。
