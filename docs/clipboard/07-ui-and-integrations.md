- 标题栏只增加**一个**剪贴板图标按钮（`TitleBar.tsx`），带

## 二、抽屉结构

```
剪贴板抽屉
├─ 头部：状态徽标（监听中/已暂停/已停用/监听未启动）
│        暂停/恢复、设置、关闭
├─ 任务关联横幅（从任务编辑器进入时显示）
├─ 工具栏：搜索（260ms 防抖）、只看收藏
├─ 类型筛选：全部/文字/链接/富文本/图片/文件
├─ 标签页：历史（total_items） / 分组（groups.length）
├─ 列表
│   ├─ 条目卡片：类型、标题（自动/手动，主行）、预览（次行弱化）、缩略图/占位、
│   │            来源/时间/大小、收藏/置顶、复制、详情、删除、多选、关联任务
│   └─ 分组卡片：名称、状态、条目/图片数·模式（合并一行弱化）、预览、
│                复制富文本/文件、粘贴、详情、收藏/置顶、删除、多选、关联
├─ 多选操作栏：复制所选（富文本）/ 复制为文件 / 逐项粘贴 / 创建分组 /
│               删除所选 / 取消选择；分组多选另有合并
└─ 底部：状态、条目/分组统计、图片缓存大小、清空历史、设置入口
```

详情视图：

- **条目详情**：标题行（2026-11-02 新增：展示自动/手动标题，手动标记“手动”；
  铅笔按钮进入编辑，`clipboard_rename_item` 保存，≤80 字符，Enter 确认 / Escape 取消；
  清空保存则按现有内容恢复自动标题）、完整正文（可折叠）、HTML 源码切换、
  图片大图（data URL 懒加载）、文件路径列表（逐个复制）、来源/时间/大小、
  复制/收藏/置顶/删除、任务关联、Agent 本地导出。
- **分组详情**：名称/状态/模式/统计、重命名、结束收集、复制富文本/文件、
  逐项粘贴入口、收藏/置顶、删除分组（保留内容/连带内容）、
  Agent 本地导出、任务关联。
  组内条目默认只显示主操作：缩略图（图片项）+ 标题优先（无标题回退预览）、
  打开详情、从分组移除；勾选拆分与上移/下移属于整理类高级操作，
  收进「整理与拆分」切换里，默认不占每条的主区域，收起时清空拆分选择。
  删除分组后条目仍保留在历史中，提示文案与后端返回一致。
- **粘贴面板**：前置校验并展示目标窗口列表（标题/exe/PID）、当前任务进度条、
  `已发送 N/M`、当前项状态、跳过/剩余、取消、继续未完成项、最终消息原样展示；
  支持两种来源：分组粘贴（分组详情入口）与**任意多选逐项粘贴**（2026-11-02 新增，
  多选栏“逐项粘贴”入口，标题显示“所选 N 项”，后端 `clipboard_paste_items`，
  任务 `group_id` 为空串）；
  逐项状态以 `pending / preparing / clipboard_written / input_sent / settling /
  unverified / failed / cancelled` 展示，失败项带原因。状态字典保留“已确认接收”
  文案，但当前没有可靠接收信号，不会出现在真实任务中；“未确认”不是失败。
  面板提示当前类型的粘贴间隔（文本/HTML/文件/图片分别取设置值），
  并说明“间隔只用于给目标留出读取时间，不代表已成功”。
  明确提示“此操作只会由你手动触发，不会在后台自动粘贴”。

### 整组复制预检

分组详情在复制前调用 `copyPreflight`（`src/lib/clipboardUi.ts`，纯前端，无额外 IPC）：

- 内嵌图片预算 6 MB：超出时提示将使用 `[图片：预览]` 占位符，并建议改用“复制为文件”；
- 含图片的富文本提示“部分富文本编辑器不接受内嵌图片”；
- 文件模式提示只传递文件路径（不复制文件内容），文本/HTML 项会被跳过；
- 单项 HTML 超过 512 KB 时提示将降级为纯文本；
- 汇总总项数/图片数/文件数，警告措辞与后端固定警告保持一致。

预检只解释限制，不改变复制结果；最终是否占位、跳过仍以后端返回的 `warnings` 为准。

## 三、状态与数据流

- `useClipboardStore`：筛选（kind/search/favorite）、分页 80、静默刷新、
  多选；刷新后自动剔除已删除的选中 id。
- 复制成功后只调用 `bumpItemCopy(id)` 就地累加使用次数，不重新请求列表：
  后端 `bump_copy` 也不再更新 `last_seen_at`，列表顺序与已加载分页保持稳定。
- 标题编辑成功后同样就地更新（`renameItem(id, title, titleSource)`，模式同
  `bumpItemCopy`），不重新请求列表、不重置分页。
- 静默刷新（后端采集/整理事件）至少按当前已加载条目数分块拉取（每块 ≤200），
  不会把多页列表缩回第一页；筛选或请求代数变化时立即放弃在途页。
- 页面与抽屉共用底部「清空历史」入口：无条目/分组时禁用，执行期间禁用重复点击，
  确认框明确说明删除范围（含收藏/置顶与内部图片缓存）以及不影响系统剪贴板、
  外部原始文件；成功后清空多选、详情并重新加载视图。
- `useUiStore`：`clipboardOpen`、`clipboardLinkTask`（携带任务进入关联模式）、
  `clipboardLinkVersion`（关联变更后任务编辑器重读）。
- 打开抽屉或筛选变化时拉取；260 ms 搜索防抖；监听 `clipboard-changed` 事件，
  300 ms 合并后静默刷新，避免高频采集导致重复请求。
- 来源为空或 `unknown` 时统一显示“未知来源”，不做猜测；来源只是前台窗口推断值。
- 头部状态区分“监听中 / 已暂停 / 已停用 / 监听未启动”，来自 `clipboard_status`；
  监听线程未启动时历史仍可查看，但空态不会暗示“正在记录”。
- 列表 DTO 已压实（正文→预览），完整内容只在详情接口读取。
- 预览截断只发生在展示层（2026-11-02 回归修复）：条目卡片标题单行、正文两行。
  约束必须写在 `.clip-preview-body` 的子元素上（`.clip-preview-body > span` /
  `.clip-preview-body > .clip-text`），且 `.clip-text` 要自带 `overflow: hidden`——
  `-webkit-line-clamp` 只压布局盒高度，缺了 overflow 时剩余行照样绘制到卡片外，
  表现为“卡片没变高、文字却盖住下一张卡”。长英文、URL、连续字符串靠
  `overflow-wrap: anywhere` 断行，不靠固定高度。原文与复制结果不受影响。
- 缩略图按需请求并缓存（LRU，最多 240 条，含并发去重）；大图只在详情打开时加载。
- 所有复制/粘贴结果使用后端返回的消息，不自行推断“成功”。

### 删除与离场反馈（2026-11-02）

删除分成三个可观察阶段，任何一步失败都不演“已成功”：

1. **执行中**：确认后到后端返回之前，目标卡片进入 `pending`（`aria-busy`、`tabIndex=-1`），
   常驻操作不可再触发；此时条目不离开列表、不出离场动画、不弹成功提示。
2. **离场**：后端确认删除后，store 用 `beginExit` 记住该行的快照与原始索引，
   组件在 `useLayoutEffect` 里把实测高度写进 `--clip-exit-h` 并加 `.removing`，
   由 `clip-remove` 关键帧收拢高度与透明度（0.19 s）；离场期间 `pointer-events: none`、
   `aria-hidden="true"`、移出 Tab 序列。列表刷新（含后台采集事件）不会提前卸载离场行。
3. **补位**：离场结束后 `endExit` 从视图剔除并触发一次静默刷新；删除开始时焦点若在卡片上，
   离场结束后交给相邻行，取不到时退回搜索框。

- 后端返回删除数量为 0（并发下已被别处删掉）时提示“这些内容已经不存在，列表已刷新”，
  不播离场动画；IPC 报错时原样展示错误，条目保持原位。
- 批量删除沿用同一条链路：一次请求、一次共享离场；后端返回数量少于请求（部分成功）时
  不整批演离场，提示“选中 N 条，实际删除 M 条，其余仍在列表中”并立即静默刷新，
  失败项保持原位，不伪装成已删除。
- 只看收藏下取消收藏是“退出筛选”而不是删除：不做删除式离场，toast 明确
  “退出「只看收藏」列表，内容仍保留在历史中”；取消置顶等排序变化只做轻量重排。
- 组内操作不套用删除语言：从分组移除只改归属（toast 说明内容仍在历史中），
  上移/下移用 200 ms 轻量位移；合并让原分组按分组离场退场，新分组随刷新出现。
- 收藏/置顶/添加分组/移出分组/合并等操作都是就地更新（`patchItem`/`patchGroup`）
  加一条带对象标题的 toast，不整表刷新；只有会改变排序的置顶会补一次静默刷新。
- `prefers-reduced-motion: reduce` 下离场延时为 0，动画由全局规则压到 0.01 ms，
  删除结果仍会落地；不为每种操作单独设计动画。

### 离场生命周期与重排规范（2026-11-03 第二轮）

第一轮落地后的生命周期修补，以下为长期有效的契约：

- **离场收尾定时器归 store 所有**：`beginExit` 为每个 id 建一个一一对应的收尾定时器
  （store 内 `exitTimers` 映射），到点自动 `endExit` 并从本地视图剔除。组件卸载
  （动画中途关闭抽屉/切页）不影响收尾——重开抽屉时以服务端数据为准，已删除的行
  不会以快照形式复活。`endExit` 幂等：组件收尾与 store 收尾先后各调一次是合法的；
  清理一个条目的定时器不影响其他离场条目。`resetClipboardRequestState` 会一并回收。
- **组内移除/拆分按展示顺序取位置**：分组详情的离场索引必须来自实际展示的行序
  （含仍在离场的行），不得用 `group.items.findIndex`——连续移除时后端列表已少了
  先前移除的条目，按它算会让后移除的行钉到已离场行的前面。
- **离场行整棵子树不可交互**：`aria-hidden` 的行/卡上必须加 `inert`，内部控件
  （含勾选框、行主按钮）同步禁用；不能只靠 `pointer-events: none`（键盘 Tab 仍可达）。
  组内移除的焦点在离场结束后交给相邻行，分组空了退回「返回分组列表」按钮。
- **FLIP 与离场互斥**：主列表（置顶/取消置顶等排序变化）与组内（上移/下移）都用
  一次 `offsetTop` 读取 + Web Animations API 位移补偿（≤60 行、`ease` 200 ms），
  不引库、不常驻 rAF。离场开始或结束的那次渲染不播重排——收拢动画已经在表达
  「下方行上移」，再叠 FLIP 会让行先跳回去再滑一遍。
- **拆分与删除的真实数量**：`clipboard_delete_group` 返回新增 `groups_deleted` 字段
  （实际删除的分组数，`delete_items` 恒为 0）；分组不存在时前端按“已经不存在，
  列表已刷新”处理，绝不演一场成功。拆分成功的条目按组内移除的同一套收拢语言离场，
  失败不播任何成功动画。
- **筛选退出 ≠ 删除**：完成任务（默认未完成筛选）与行动中心标记已处理（默认不含
  已处理）使用 `list-collapse-out`（淡出收拢、无删除侧移语言），动画结束后才提交
  刷新；失败立即弹回原位。「历史」分类确认后行仍留在列表，不播退出动画。
  空列表出现用 0.18 s 轻量淡入（`soft-fade-in`）。

## 四、可访问性与交互

- 抽屉 `role="dialog" aria-modal="true"`，打开后聚焦，`tabIndex=-1`。
- Escape 分层：确认框 → 详情 → 抽屉；标题栏的“Escape 隐藏窗口”在抽屉打开时跳过，
  不会把主窗口一起藏进托盘。
- 图标按钮均有 `aria-label`，悬停提示统一用 `data-tip`（不用原生 `title`）；
  开关类按钮使用 `aria-pressed`；
  标签页使用 `role="tab"`/`aria-selected`；确认框 `role="alertdialog"`。
- 类型筛选使用 `role="group"`，目标窗口列表使用 `role="radiogroup"`。
- 破坏性操作二次确认；确认框点击遮罩取消。
- 动画：抽屉 0.18 s 滑入；全局 `prefers-reduced-motion: reduce` 将动画/过渡降到 0.01 ms。
- 主题：全部颜色走 CSS 变量；毛玻璃模式使用 `color-mix` 半透明覆盖层，
  不支持材质时回退为现有 solid 主题。

## 五、设置页

设置面板新增“智能剪贴板”分区（`SettingsPanel.tsx`）：

- 总开关、暂停（抽屉内亦可一键暂停/恢复）、采集图片/文件/HTML、自动分组与窗口秒数；
- 保留天数、最大条目数、最大存储 MB、分类型粘贴间隔
  （文本 350 / HTML 600 / 文件 900 / 图片 1200 ms，范围 100–5000）；
- 敏感内容过滤开关（说明“只识别高置信特征，不能保证识别全部密码/令牌”）；
- 来源未知时额外启用保守凭据模式（说明只覆盖常见 `password=`/Bearer/JSON 凭据字段，
  不能替代关闭监听）；
- 应用排除名单（逗号/换行分隔，失焦保存，≤4096 字符；写成完整路径时按 exe 文件名比较；
  说明无法识别来源的复制不受名单保护）；
- 存储/条目统计、手动清理、当前剪贴板可读性诊断（`clipboard_probe`，
  只返回类型/大小/文件数，不返回正文）；
- 所有输入使用后端范围校验，非法值返回明确错误。

## 六、任务集成

- **从任务编辑器关联**：任务编辑器的“关联剪贴板（手动）”区域打开抽屉并携带任务；
  抽屉顶部横幅提示选择条目/分组；选择后写入 `clipboard_task_links`，抽屉关闭，
  `clipboardLinkVersion` 自增，任务编辑器重新读取关联列表。
- **从剪贴板详情关联**：条目/分组详情内的“关联任务”下拉选择任务（最多 100 个），
  手动点击“关联”。
- **任务编辑器展示**：列出已关联条目/分组（类型 + 预览），可取消关联；
  提示“不会自动绑定；删除任务不会删除剪贴板内容”。
- **删除语义**：删除任务只级联删除关联行；剪贴板内容与分组保留（有单测覆盖）。
- 不做自动绑定、不做“任务创建时自动抓取剪贴板”。

## 七、Agent 集成

`clipboard_agent_targets` 返回已注册 Agent 的 `display_name` / `installed` /
`window_present` / `note`，并给出四项能力（`AgentCapability { supported, evidence, note }`）：

| 能力 | 当前结论 | 证据字段 | 说明 |
|---|---|---|---|
| 直接发送（结构化接口） | 不支持 | `unsupported-interface` | 未发现经用户授权、稳定且可验证的本地发送接口；不绕过权限、不使用未公开协议 |
| 文件导入 | 未验证 | `unverified` | 未验证到官方文件导入接口；导出包需用户在 Agent 中手动附加 |
| 桌面粘贴 | 有窗口时可手动触发 | `window-present` / `exe-found` / `not-installed` | 只代表按键动作已发送，接收无法自动验证 |
| 本地导出 | 可用 | `local-export` | 只写本地文件，不上传、不写入 Agent 会话 |

界面明确区分“直接发送 / 仅发送按键 / 仅本地导出 / 不支持 / 未验证”，
并给出推荐方式（有窗口推荐提示粘贴，否则推荐导出）。**导出的目标选择不影响导出内容**：

- “导出给 Agent”只生成**本地文件包**：`clipboard-exports/<8位id>/`
  - `clipboard.md`：标题、导出时间、条目数、分组方式、可选任务上下文、
    按组内顺序的条目内容（图片以独立 PNG 引用）；
  - 图片文件：`image-01.png` 等；
  - `manifest.json`：导出时间、目标类型/id、标题、任务 id、条目元数据、
    文件列表、警告与“不自动上传”声明。
- 导出前 UI 明确说明“不会自动上传或发送给任何 Agent；请在目标 Agent 中手动附加文件”。
- 任务上下文只在用户从任务关联入口导出时写入，且任务不存在时给出警告。
- 不调用任何网络接口、不写入 Agent 会话、不自动发送。

| 监听线程未启动 | 状态“监听未启动”（tone-bad），历史仍可查看/复制 |
| 总开关停用 | 状态“已停用”，暂停按钮禁用，空态提示去设置开启 |
| 暂停 | 状态“已暂停”，可恢复；历史仍可操作 |
| 无记录 | 空态说明“复制文字、图片或文件后会自动出现在这里” |
| 无分组 | 空态说明连续截图自动成组 / 可手动创建 |
| 图片缺失 | 卡片显示占位，详情提示；复制/粘贴返回明确错误 |
| 后端错误 | 列表显示错误 + 重试按钮；操作 Toast 显示错误文本 |
| 粘贴完成 | 原样展示后端消息，包含“目标应用是否接收无法自动验证” |
