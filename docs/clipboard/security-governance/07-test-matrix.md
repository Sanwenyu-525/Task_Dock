## 3. 证据与环境要求

- 隔离数据目录：`TASK_DOCK_DATA_DIR=tmp/acceptance/<task-name>/`；独立实例端口/缓存。
- DPAPI/ACL/真实剪贴板行为必须真机；单元测试中的 DPAPI 失败路径用桩验证逻辑，不冒充系统行为。
- 每条用例记录：命令、工作目录、退出码、产物路径、关键计数；失败单列现象/根因/影响，不把 ignored 计为通过。
- 性能基线：加密热路径（采集入库、列表加载、图片解密预览）附 p50/p95 与样本数；不得用短采样宣称无性能回退。

## 4. 暂不覆盖（残余风险登记）

- 运行时同用户恶意进程读内存/调 DPAPI。
- SSD 物理残留、回收站、卷影副本、崩溃转储。
- 用户手动另存/网盘同步出去的副本。
- 图片内容级敏感识别（人脸/证件/截图文字）。
- 密文全文检索性能（实施阶段单独评估）。
