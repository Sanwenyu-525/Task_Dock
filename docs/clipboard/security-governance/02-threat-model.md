# 02 · 威胁模型（剪贴板隐私与数据安全专项）

| 项目 | 内容 |
|---|---|
| 状态 | 第一阶段调查结论（待主 Agent 审核） |
| 日期 | 2026-11-23 |
| 范围 | 剪贴板历史（文本/HTML/图片/文件路径/来源元数据）、关联备份、Agent 导出、本机存储 |
| 原则 | 不降低现有基线；承认「模式过滤 ≠ 内容加密」；威胁分级与可缓解项对应到测试矩阵 |

## 1. 资产清单

| 资产 | 位置 | 敏感度 | 说明 |
|---|---|---|---|
| 剪贴板正文（text/html/preview/title） | `task-dock.db`、WAL、备份 bundle、导出 `.md`、staging JSONL | 高 | 可能含密码、令牌、证件号、私信、会议纪要、财务信息 |
| 图片原图/缩略图/预览缓存 | `clipboard/images/`、`clipboard/thumbs/`、备份 bundle、导出目录 | 高 | 截图可含密码框、人脸、证件、聊天记录、代码密钥 |
| 文件路径清单 | `clipboard_items.file_paths`、导出 Markdown | 中 | 路径含用户名、目录结构、项目/客户名 |
| 来源元数据 | `source_app/source_title/source_kind` | 中 | 窗口标题常含隐私；来源不可靠，不作信任边界 |
| 去重哈希 | `content_hash` | 中低 | 可离线比对/爆破短口令；不作为机密保护依据 |
| 配置与排除名单 | `application_settings` | 低 | 策略明文；`clipboard_config_corrupt_backup` 需复核 |
| 派生密钥/封装密钥 | 本方案新增（见 ADR） | 最高 | 只存封装态；明文密钥不出受保护内存 |

## 2. 信任边界

- **进程内**：Tauri 主进程 / Rust 后端 / WebView 前端；IPC 经 `bridge.ts` 受控命令。
- **本机磁盘**：SQLite、`clipboard/`、`clipboard-exports/`、备份目录、staging、系统临时目录。
- **本机其他进程**：同用户下的其他应用；已获授权的本地 Agent/MCP 适配器。
- **同机其他 Windows 用户**：跨用户边界；管理员与标准用户分别评估。
- **外部通道**：剪贴板本身是系统级共享；TaskDock 不主动上传，但备份/导出文件可能被用户拷贝、同步到网盘或换机。
- **不纳入本方案边界**：恶意已获权进程在 TaskDock 运行时读取其内存；硬件 rootkit；键盘记录；蓝屏转储中残留的瞬时明文（仅记录为残余风险）。

## 3. 威胁参与者（STRIDE 简化）

| 编号 | 参与者 | 能力 | 目标 |
|---|---|---|---|
| T1 | 同机另一 Windows 用户（标准用户） | 访问未做 ACL 限制的用户目录、备份盘 | 读取他人剪贴板历史/图片 |
| T2 | 同机管理员 / 取证人员 | 读取卷影副本、磁盘镜像、备份文件、`.previous` 轮换文件 | 恢复已删除的历史 |
| T3 | 同用户下的其他进程 / 被攻陷的本地 Agent | 经 IPC、文件系统、Agent 导出包读取历史 | 越权带出正文/图片 |
| T4 | 拿到备份 bundle / 导出目录的人 | 离线打开 JSONL、base64、PNG、Markdown | 在换机/丢盘/网盘泄露场景读取内容 |
| T5 | 恶意/误配置应用写入剪贴板 | 触发采集、注入伪装来源 | 污染历史；把凭据从密码管理器外的通道带入 |
| T6 | 内部误操作 | 清空失败、迁移中断、恢复旧备份 | 数据损坏或旧明文回流 |
| T7 | 供应链/磁盘残留 | SSD 未覆写、回收站、临时文件残留 | 事后取证恢复已删内容 |

## 4. 威胁清单与现状/目标缓解

### 4.1 静态存储泄露

| 编号 | 威胁 | 现状 | 目标缓解（方案阶段） | 残余风险 |
|---|---|---|---|---|
| S1 | 明文库被直接拷贝读取 | 正文/HTML/预览明文落 SQLite | 字段级或记录级静态加密；DEK 经 DPAPI 封装；库内只存密文+nonce+AAD | 运行时进程内存仍有明文；离线拷库不可读 |
| S2 | 图片文件被直接读取 | 原图/缩略图/预览缓存明文 PNG | 资产文件加密落盘（或加密容器目录）；读取时按需解密到受保护内存 | 缩略图/预览是降采样派生，仍可能泄露部分信息 |
| S3 | WAL/SHM/临时文件残留明文 | WAL 未做隐私 checkpoint；`.tmp` 崩溃残留 | 迁移后 checkpoint 策略；临时文件最小化、失败即清；删除后按策略 checkpoint；哨兵扫描覆盖 WAL | 崩溃瞬间残留窗口；SSD 磨损均衡下文件块可能残留 |
| S4 | 备份 bundle 明文 | 正文 + base64 图片随 bundle 明文 | 备份加密层：备份密钥独立封装；可选跨设备恢复口令；bundle 头标注加密版本 | 无密钥的备份不可恢复；密钥丢失需走恢复流程 |
| S5 | Agent 导出包明文留存 | `clipboard-exports/` 明文目录 | 导出前预览与一次性确认；明示风险；手动清理 + 可选启动自动清理；审计记录 | 用户主动另存的副本、已开启前的历史导出与关闭自动清理时的留存不在应用保证内 |
| S6 | 配置损坏备份/诊断日志回含正文 | 日志原则上不记正文；损坏配置备份待复核 | 逐列复核；诊断层白名单；哨兵扫描覆盖设置键与日志 | — |

### 4.2 访问控制与越权

| 编号 | 威胁 | 现状 | 目标缓解 | 残余风险 |
|---|---|---|---|---|
| A1 | 跨 Windows 用户读取数据目录 | 依赖 `%APPDATA%` 目录默认 ACL，未显式加固 | 数据目录/剪贴板目录显式受限 ACL（仅当前用户+管理员）；密钥 DPAPI 当前用户作用域，跨用户不可解 | 管理员仍可取得所有权读取；属 Windows 模型固有 |
| A2 | 未授权 Agent 读取/导出剪贴板 | 能力矩阵存在；导出授权落点待复核 | 剪贴板读取/导出纳入 `agent_access` 能力白名单；逐次授权或按能力授予；审计落 `security_audit_log` | 已授权 Agent 在授权范围内可读 |
| A3 | 前端越权拉取历史 | IPC 经 bridge | 复用现有命令鉴权；加密后前端只在解密会话内拿到明文 | — |
| A4 | 排除名单/来源推断被当作安全边界 | 文档已声明来源不可靠 | UI 与文档延续「来源不是安全边界」口径；未知来源走保守过滤 | 识别不到来源的应用不受排除名单保护 |

### 4.3 采集与内容识别

| 编号 | 威胁 | 现状 | 目标缓解 | 残余风险 |
|---|---|---|---|---|
| C1 | 凭据/私钥被采集入史 | 高置信 + 保守模式正则；明确不保证全覆盖 | 保留现有过滤；隐私文案声明局限；加密兜底「即使漏过滤，静态库不可离线读」 | 正则漏网内容在运行时仍可见；图片内文字无识别 |
| C2 | 敏感截图入史 | 无内容级识别 | 图片采集独立授权；关闭图片采集即不落原图；不引入云端识别 | 本地图像分类不在本期范围 |
| C3 | 隐私标记应用未被识别 | 依赖应用主动设置 | 现状保留；文档声明局限 | 部分应用不设置标记 |
| C4 | 自写回流 | 序列号水位 + ACCESS_LOCK 锁内复核 | 不改动既有隔离；加密层不破坏自写判定 | — |

### 4.4 迁移、恢复与可用性

| 编号 | 威胁 | 现状 | 目标缓解 | 残余风险 |
|---|---|---|---|---|
| M1 | 明文→密文迁移中断留半套 | 现有迁移单事务原子提交 | 迁移分阶段：备份验证 → 加密副本 → 校验 → 切换；断点续跑；失败回滚到原始明文库 | 极端断电需人工按回滚流程处理 |
| M2 | 迁移后明文残留（旧页/旧文件/WAL） | 无哨兵扫描 | 哨兵字符串 + 明文模式扫描库、WAL、资产目录、导出目录；扫描不过不切正式态 | 空闲页/SSD 残留不在应用层保证 |
| M3 | 恢复旧明文备份到加密库 | 恢复假定同等级 | 备份格式版本门禁；明文备份导入时提示并走一次性迁移；密钥绑定关系校验 | 跨版本恢复需兼容矩阵 |
| M4 | 密钥丢失导致历史不可读 | 无密钥体系 | 见 ADR 密钥丢失风险与恢复方式；可选独立恢复口令/恢复包 | 用户不保存恢复材料则数据不可恢复（设计内取舍） |
| M5 | 加密改造破坏工作篮/任务关联 | 关联靠 UUID 外键 | 加密只作用于内容字段，不动主键/外键/关联表；往返测试覆盖任务链接、分组、快照链接 | — |

## 5. 不承诺事项（诚实边界）

1. 不承诺识别全部敏感内容：正则/标记只是前置过滤，静态加密是兜底，不是内容分类。
2. 不承诺防运行时内存读取：获得本机管理员/调试权限的进程可读取运行中进程内存。
3. 不承诺擦除 SSD/回收站/卷影副本中的物理残留；应用层删除不等于覆写。
4. 不承诺保护用户主动另存、手动备份、网盘同步出去的副本。
5. 图片缩略图/预览是降采样派生，加密保护其文件，但派生信息本身可能仍可读。
6. 来源应用/窗口标题不可靠，不作为可信身份或授权依据。

## 6. 风险分级口径（与验收 P0–P3 对齐）

- **P0**：跨用户可直接读取明文库/图片；密钥明文落盘；迁移导致历史或关联丢失；备份/导出绕过加密层携带正文。
- **P1**：已授权通道外可经 Agent 导出历史；WAL/临时文件长期滞留明文；备份明文可离线解。
- **P2**：预览缓存清理仍有边界；导出目录自动清理默认关闭、需用户开启；元数据（路径/标题）泄露；ACL 未显式加固。
- **P3**：文案局限说明不到位；诊断计数口径偏差；派生缓存命名/清理不一致。
