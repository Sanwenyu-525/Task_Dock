# 04 · 隐私授权设计

| 项目 | 内容 |
|---|---|
| 状态 | 方案设计（待审核授权后落地 UI/命令） |
| 日期 | 2026-11-23 |
| 范围 | 采集授权、图片授权、监听控制、保留期、来源排除、过滤局限口径、Agent 导出授权 |
| 原则 | 默认最小采集；授权可撤回；所有限制如实说明，不宣传绝对安全 |

## 1. 授权模型现状与目标

### 1.1 现状

- 设置项已有：`clipboard_enabled`（总开关）、`clipboard_paused`（临时暂停）、`clipboard_capture_images`、`clipboard_capture_files`、`clipboard_capture_html`、`clipboard_retention_days`、`clipboard_max_items`、`clipboard_max_storage_mb`、`clipboard_exclude_apps`、`clipboard_sensitive_filter`、`clipboard_ocr_auto`。
- 首次启动**尚无独立的采集授权引导**；开关存在于设置页，但新用户在未明确知情的情况下可能已被默认采集。
- 备份恢复时 `clipboard_enabled` / `clipboard_paused` 不写回本机（`LOCAL_PRIVACY_SETTINGS`），避免旧备份重新打开采集。

### 1.2 目标

1. **首次明确授权**：首次进入剪贴板功能（或首次启动检测到剪贴板模块可用）时，展示授权说明：采集什么、存哪里、是否含图片、可随时关闭/清空；用户显式同意后才开启采集。未同意 = `enabled=false / paused=true`（fail-closed 口径与现有配置损坏语义一致）。
2. **图片采集单独授权**：图片是高敏资产（截图含密码框/人脸/证件），与文本采集分开开关；关闭后不写原图、不写缩略图/预览缓存。
3. **授权状态可见、可撤回**：设置页与抽屉状态明确区分「未授权 / 监听中 / 已暂停 / 已停用 / 配置异常」。
4. **撤回不删除历史**：关闭采集只停止新记录；历史是否保留由「清理全部历史」与保留期控制，避免静默删除用户数据。

## 2. 授权与控制项设计

| 能力 | 控制项 | 行为 | 现状对接 |
|---|---|---|---|
| 采集总授权 | 首次授权确认 + `clipboard_enabled` | 关闭后监听线程不读取、不入库；不删历史 | 已有开关，补首次引导与文案 |
| 临时暂停 | `clipboard_paused` | 暂停期间不补录；恢复后只记新事件 | 已有 |
| 图片采集 | `clipboard_capture_images` | 关闭：图片事件跳过，不落原图/缩略图/预览缓存；文件/文本不受影响 | 已有开关，补独立说明与清理联动 |
| 文件路径采集 | `clipboard_capture_files` | 关闭：文件列表条目不记录路径 | 已有 |
| HTML 采集 | `clipboard_capture_html` | 关闭：HTML 片段不保存，纯文本回退按现有判定 | 已有 |
| 清理全部历史 | 现有清理命令 | 清空条目 + 关联资产 + 预览缓存 + 导出目录策略（见 §5）；OCR 缓存失效 | 已有，补缓存/导出覆盖核对 |
| 保留期 | `clipboard_retention_days` / `clipboard_max_items` / `clipboard_max_storage_mb` | 非收藏/非置顶按天、条数、容量淘汰；收藏置顶不被自动清理 | 已有 |
| 来源应用排除 | `clipboard_exclude_apps` | 按 exe basename 大小写不敏感匹配；命中跳过；文档声明排除名单不是安全边界 | 已有 |
| 敏感过滤 | `clipboard_sensitive_filter` | 高置信模式始终过滤；保守模式仅来源未知时启用；可关闭但需明示风险 | 已有，文案补局限 |
| OCR 自动识别 | `clipboard_ocr_auto` | 现状第一阶段仅存设置值，不接采集热路径；不上传 | 已有，保持 |

## 3. 首次授权流程（草案）

1. 检测到剪贴板模块首次启用（无授权记录键）→ 不启动采集读取。
2. 展示授权说明（本地文案，要点）：
   - 会记录复制的文本/链接/网页片段；可选是否记录图片与文件路径。
   - 历史只保存在本机应用数据目录；可在设置中暂停、关闭或清空。
   - 应用会尝试识别并跳过部分私钥/令牌，但**不能保证识别全部敏感内容**；涉及高度敏感内容时建议暂停监听或排除对应应用。
   - 图片不做内容识别；截图中的文字/画面是否敏感由用户判断。
3. 选项：「仅文本」「文本 + 图片」「暂不开启」。选择前两者写对应授权键；选择暂不开启保持关闭，下次进入可再引导。
4. 授权键纳入 `application_settings` 白名单与默认值；旧库升级时不替用户默认同意——沿用既有采集状态但在设置页提示补确认（具体策略实施评审定，避免静默改变现有用户行为）。

## 4. 敏感内容过滤的文案口径（强制）

所有面向用户的位置（设置页、抽屉、帮助、导出提示、备份说明）统一使用以下口径，禁止出现「安全加密全部密码」「自动保护所有敏感信息」类表述：

- 过滤基于固定特征匹配（私钥头、常见令牌格式、凭据赋值结构、认证头、JSON 凭据字段），**可能漏识别**自定义令牌、验证码、银行卡号、手写密码、截图内文字。
- 来源未知时启用更保守的凭据匹配，但仍不保证全覆盖。
- 排除名单只覆盖能推断出来源的应用；识别不到来源的复制不受其保护。
- 静态加密保护的是落盘后的历史；采集那一刻已进入内存/剪贴板系统不在加密范围内。
- 开关开启时覆盖 `text/html/preview/title/source_app/source_title/file_paths` 与图片资产；
  仍可见的见证元数据只有类型、尺寸、大小、哈希、时间与收藏状态。搜索在解密后过滤，
  最多覆盖排序前 5000 条，不保留明文索引。
- 高敏感场景（密码管理器、证件、财务）建议直接暂停监听或把对应应用加入排除名单。

## 5. 清理与生命周期联动

| 对象 | 删除/清理触发 | 现状核对项 |
|---|---|---|
| 条目行（text/html/preview/title/paths/source） | 单删、清空、过期淘汰 | 密文形态下删除逻辑不变；删除后触发 WAL checkpoint 策略（迁移方案 §5） |
| 原图 `images/<id>.png` | 条目删除且无引用 | FK CASCADE + `remove_files_unreferenced`；加密文件同链路 |
| 缩略图 `thumbs/<id>.png` | 同上 | 同上 |
| 预览缓存 `thumbs/<id>-preview-640.png` | 条目删除/清空/缓存失效 | **现状不在 `clipboard_assets` 引用集合内**，需补清理覆盖，避免孤儿加密缓存 |
| OCR 缓存 | 条目/分组/清空失效 | 现有代数机制保留 |
| Agent 导出目录 `clipboard-exports/` | 不随历史自动删除；需策略 | 批次 5a 已提供设置页「清理 Agent 导出」：按保留天数手动删除过期导出目录（默认 7 天，需确认），不自动运行；导出条目在历史删除后标注孤立、自动清理与授权审计仍未实现 |
| staging 临时文件 | 备份读取/恢复完成后 | 失败路径必须清理；崩溃残留由下次启动扫描 |
| 配置损坏备份 `clipboard_config_corrupt_backup` | 配置修复后按策略保留 | 复核是否回含敏感文本；必要时纳入清理 |

## 6. Agent 导出授权（草案）

现状：`agent_bridge::export_package` 按条目/分组生成本地明文包，含正文、HTML、原图、关联任务描述；能力矩阵区分直接发送/文件导入/粘贴/导出证据等级。

目标补齐：

1. **能力登记**：剪贴板读取、剪贴板导出纳入 `agent_access` 能力白名单（如 `clipboard.read` / `clipboard.export`）；未授予的 Agent 不可触发导出。
2. **逐次或按范围授权**：导出范围（单条/分组/含任务上下文/含图片）在授权粒度上可见；导出前在 UI 明示将带出哪些内容类型。
3. **审计落点**：导出事件记录主体、时间、范围类型、条目数、图片数、目标 Agent；**不记录正文/图片/路径正文**（沿用现有日志原则），写入 `security_audit_log` 或既有剪贴板审计表。批次 5b 已实现：`category=clipboard`，只记目标类型/条目与图片计数/错误码；主体与目标 Agent 标识仍待随授权模型补齐。
4. **本地留存提示**：导出包仅在本机；提示用户导出目录可被其他同用户进程读取；提供清理入口（批次 5a 已提供手动按保留期清理，自动清理未实现）。
5. **任务上下文带出**：关联任务标题/描述进入导出包前，按任务读取授权复核，不默认带出。

## 7. 隐私设置与备份的关系

- `clipboard_enabled`、`clipboard_paused` 继续属于 `LOCAL_PRIVACY_SETTINGS`：备份可存，恢复不写回本机，防止旧备份在用户不知情时重启采集。
- 图片授权、排除名单、保留期是否随备份迁移：实施评审定；建议采集偏好随备份迁移，但「是否当前开启采集」始终以本机为准。
- 加密备份包的恢复不自动开启采集；恢复后采集状态保持本机当前选择。

## 8. 未决项

1. 首次授权的触发时机（首启 vs 首次打开剪贴板抽屉）与旧库升级用户的补确认策略。
2. 导出目录保留期与自动清理是否默认开启。
3. 密文形态下搜索的可见范围（见 ADR §13 未决项）：**已定（批次 6）** 不建明文索引，解密后过滤，最多 5000 条。
4. 排除名单是否支持窗口标题/来源类型规则（本期建议不扩展，保持 exe 名匹配）。
