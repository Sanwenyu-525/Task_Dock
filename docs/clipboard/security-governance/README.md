## 核心结论（摘要）

1. **治理前缺口（保留为基线）**：库内正文/HTML/预览、图片原图/缩略图/预览缓存均为静态明文；WAL 与临时文件可能滞留明文；备份 bundle 与 Agent 导出包明文；跨用户只靠目录 ACL，无密码学边界。批次 1–9 已覆盖正文、可检索元数据、图片、加密备份、导出前确认、可选启动清理与显式目录 ACL；Agent 导出包仍为明文。
2. **推荐选型**：剪贴板独立随机 CEK，DPAPI 当前用户作用域封装；备份用独立 BEK 与恢复口令/密钥包；**不复用保险箱 DEK/KEK**；预留未来口令 slot 扩展。
3. **迁移原则**：备份验证通过前不动旧数据；影子库 + 断点续跑 + 对账 + 哨兵扫描后才原子切换；观察期保留旧副本；中断可续跑或回滚。
4. **隐私口径**：敏感过滤是固定模式匹配，不保证识别全部凭据；图片无内容识别；来源应用不是安全边界——UI 与文档不得宣传绝对安全。
5. **边界外**：不防运行时同用户恶意进程读内存；不擦除 SSD/回收站/卷影副本物理残留；不保护用户主动另存的副本；本期不做密文全文检索与图像敏感分类。

## 待审核未决项

- 备份恢复 slot：恢复口令 Argon2id / 离线密钥包 / 双 slot。
- 密文检索可见范围（是否保留有限明文索引）。
- 资产加密容器布局与预览缓存归属层。
- 数据目录显式 ACL 的真机/跨用户验证方式。
- 旧库升级用户的首次授权补确认策略。
- 导出目录自动清理默认关闭，需用户显式开启；保留天数手动与自动共用（批次 8 已定）。
