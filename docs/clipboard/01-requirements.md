# 01 · 需求与验收范围

> 版本：v0.5.0（与 `Cargo.toml` / `tauri.conf.json` 一致）
> 范围：Task Dock 内置「智能剪贴板」子系统
> 原则：真实实现、本地优先、显式触发、不夸大验证级别

## 一、目标

在现有 Task Dock（Tauri 2 + React 19 + Rust）中集成一个真实的智能剪贴板，
覆盖 **采集 → 去重 → 历史 → 自动分组 → 手动整理 → 复制/逐项粘贴 → 任务关联 → Agent 本地导出**
的完整闭环，同时不破坏任务、Agent 监控、统一导航等既有能力。

它不是独立应用，不引入第二套数据库、独立状态容器或第二套窗口体系：

- 数据库复用现有 SQLite 与迁移机制；
- 界面复用现有主题、组件与标题栏，仅新增一个次级抽屉；
- 任务/Agent 集成复用现有 `tasks`、Agent 注册表与导航目标体系；
- 所有剪贴板自动化只在用户显式操作时发生。

## 二、用户工作流

1. 用户复制文字、链接、富文本、截图、文件列表，系统自动记录（可随时暂停/停用）。
2. 连续截图在默认 45 秒窗口内自动成组；截图之间复制的文字不会打断顺序，而是按实际
   发生顺序插入组内。
3. 用户打开剪贴板抽屉，搜索、按类型/收藏筛选，查看大图与完整正文。
4. 用户可把自动组改名为「周报素材」，重排、拆分、合并、收藏、置顶、删除。
5. 用户把整组富文本或文件一键复制，或选择目标窗口后逐项粘贴（带队列进度与取消）。
6. 用户可在任务编辑器中把某个条目/分组手动关联到任务，并在任务详情中回看。
7. 用户可把条目/分组导出为本地 Agent 导入包（Markdown + 图片 + manifest），
   由用户自行交给 Agent；Task Dock 从不上传、从不自动发送。

## 三、功能需求

### 1. 采集与历史

- 自动记录：纯文本、URL、HTML 富文本、截图/图片、文件列表（含多文件）、混合内容。
- 去重：内容哈希唯一；再次复制只更新使用次数、时间与来源，不新增历史条目。
- 每条记录包含：类型、时间、大小、来源应用/窗口标题、预览、完整内容（图片落文件）。
- 列表按最近使用排序，支持搜索（文字/来源/文件名）、类型筛选、收藏筛选、
  分页加载（每页 80，默认上限 1000 条，可配置）。
- 收藏/置顶条目不被自动清理；删除遵守引用安全，不误删仍被引用的图片。

### 2. 自动分组

- 连续截图在配置窗口（默认 45 秒，可配 5–600 秒）内自动进入同一收集组。
- 截图之间夹杂的文字/HTML/URL 按实际顺序追加到当前组；文件列表不参与截图分组。
- 组内条数达到 300 条后，下一张截图开新组；窗口过期、手动结束、应用重启均结束收集。
- 分组引擎为纯函数，可单元测试，不依赖 UI/数据库/系统时间（时间由调用方传入）。

### 3. 手动整理

- 新建手动分组、重命名、结束收集、收藏、置顶、删除（可选择是否连同条目）。
- 组内：上移/下移、移除（不删除内容）、拆分出新组、多组合并。
- 所有破坏性操作必须二次确认；删除分组默认保留条目。

### 4. 复制与粘贴

- 单项复制：文字/HTML/图片/文件列表，尽可能保留原始格式。
- 整组复制：
  - 富文本模式：按组内顺序拼接 HTML，图片内嵌为 data URI（有大小上限并给出警告）；
  - 文件模式：把组内文件条目合并为一次多文件复制。
- 逐项粘贴：选择目标窗口后，按组内顺序逐项写入剪贴板并发送 Ctrl+V；
  可配置间隔，支持取消、失败停止、继续未完成项；同一时刻只允许一个粘贴任务。
- 诚实状态：只对「按键动作已发送」负责，界面必须显示
  「已发送 N/M 项粘贴动作；目标应用是否接收无法自动验证」，不得宣称粘贴成功。

### 5. 剪贴板保护

- 粘贴前快照原剪贴板；粘贴结束仅在剪贴板序列号仍等于本进程最后一次写入时恢复。
- 粘贴期间用户或其他程序写入新内容时，绝不覆盖，状态说明「保留最新内容」。
- 原剪贴板为空或格式不支持时，明确说明「未做恢复」。
- 自身写入不会产生新的历史记录（序列号隔离 + 来源应用过滤）。

### 6. 任务与 Agent 集成

- 任务 ↔ 剪贴板：手动关联/取消关联；任务详情可查看关联条目/分组。
  删除任务只删除关联关系，绝不删除剪贴板内容；不做自动绑定。
- Agent：提供统一的本地导出接口（文字/图片/有序分组/可选任务上下文），
  导出前显示统计；能力探测如实标注目标 Agent 是否可用；不自动上传、不自动发送。
- 工作现场快照关联（v0.5 并行模块）：命令层提供条目/分组与快照的关联接口，
  当前 UI 尚未接入（见 09 遗留项）。

### 7. 界面

- 标题栏只增加一个剪贴板图标；抽屉为内容区内的次级面板，不新增主标签页。
- 复用现有主题（含毛玻璃）与 CSS 变量；动画可被系统的「减少动态效果」关闭。
- 长列表分页 + 缩略图缓存上限 + 图片按需加载，避免一次性渲染全部内容。
- 键盘与可访问性：抽屉 focus 管理、Escape 分层关闭（确认框 → 详情 → 抽屉，
  不隐藏主窗口）、按钮 aria-label/aria-pressed、对话框语义。
- 设置页提供剪贴板分区：开关、采集类型、自动分组窗口、保留期、条数/容量上限、
  排除应用、粘贴间隔、敏感过滤、清理与诊断。

## 四、非功能需求

### 安全与隐私

- 纯本地：无云同步、无遥测上传、无默认 Agent 发送。
- 日志只记录类型/大小/计数/失败原因，**绝不记录剪贴板正文、完整图片、密码或令牌**。
- 尊重系统/密码管理器标记（`ExcludeClipboardContentFromMonitorProcessing`、
  `Clipboard Viewer Ignore`、`CanIncludeInClipboardHistory=0`）。
- 高置信敏感特征过滤（PEM 私钥、AWS/GitHub/Slack 令牌样式）默认开启；
  明确不宣称能识别全部密码/令牌。
- 应用排除名单（按小写 exe 名）与全局暂停/停用。
- 所有粘贴自动化必须由用户点击触发；无后台自动粘贴。

### 性能与稳定性

- 空闲监听不轮询：使用 Win32 剪贴板格式监听消息，事件驱动。
- 单条正文 ≤ 512 KB（超出不记录）、单图 ≤ 64 MB、文件数 ≤ 200、缩略图最长边 192 px。
- 图片/缩略图落磁盘文件，数据库只存元数据与相对路径；不做 BLOB。
- 历史列表分页；搜索使用索引友好的 LIKE 前缀/包含查询并转义通配符。
- 清理任务在后台线程周期执行，不阻塞 UI；删除后清理无引用资产文件。
- 应用启动时监听失败只降级为「不自动记录」，不阻塞主程序。

### 兼容性

- 平台：Windows 10/11（Win32 剪贴板 + SendInput）。
- 非 Windows 提供编译桩：读为空、写返回明确错误、监听不可用；界面如实显示「监听未启动」。
- 目标应用兼容性按真实测试记录（见 08），未测试的应用不得写成已支持。

## 五、明确不做（本期）

- 不做云同步/跨设备同步。
- 不做自动发送给 Agent 或任何网络服务。
- 不做「100% 敏感内容识别」承诺。
- 不做图片 OCR、以图搜图、全文索引图片内容。
- 不做非 Windows 的真实剪贴板监听实现。
- 不把模拟测试、单元测试或固定延迟当作真实应用粘贴成功。
- 不自动绑定任务与剪贴板内容。

## 六、验收标准（对应最终交付 A–I）

1. 智能剪贴板真实集成，能记录文字、截图、文件。
2. 连续截图自动分组，混合内容顺序正确。
3. 历史持久化、重启不丢；删除安全。
4. UI 不破坏悬浮栏布局；入口唯一、可关闭。
5. 单项复制与整组复制真实可用（命令层写入系统剪贴板）。
6. 逐项粘贴具备可运行的 Windows 实现，明确已验证/未验证目标。
7. 失败/取消可安全退出，剪贴板不覆盖用户新内容。
8. 任务关联可用；Agent 导出遵守能力边界。
9. 隐私控制实现；日志不含正文。
10. 自动化测试、构建通过，或明确列出环境阻塞与失败。
11. 文档与代码同步；未完成项不得标为完成。
