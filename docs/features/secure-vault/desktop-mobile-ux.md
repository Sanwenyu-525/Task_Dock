# 安全保险箱 · 桌面端与移动端交互设计

- 日期：2026-11-18
- 阶段：P0（交互方案；页面实现在 P1/P2）
- 上游：[product-requirements.md](product-requirements.md)、[security-architecture.md](security-architecture.md)

> 视觉基线：**继承 Task Dock 现有设计系统**（`styles-themes.css` 语义 Token、`components/ui/*` 基元、
> `overlayStack`、`data-tip`）。保险箱只增加"安全语义"的视觉表达（锁定遮罩、敏感区折叠、复制反馈），
> **不另造一套设计语言**。

---

## 1. 设计原则

| # | 原则 | 具体落地 |
|---|---|---|
| 1 | 锁定态不泄漏内容 | 锁定页只有图标 + 主密码框；**不显示记录数、最近标题、分类名** |
| 2 | 秘密默认不可见 | 所有 `password/secret/blob` 字段默认 `••••••`；点击眼睛才显示，且 30 秒后自动隐藏 |
| 3 | 复制是一等操作 | 列表/详情都有复制按钮；复制后 Toast + 倒计时；不自动复制 |
| 4 | 少即是安全 | 新建表单按类型分模板；不一次性铺 20 个输入框 |
| 5 | 键盘可达 | 搜索 `Ctrl+K`（面板内）、`Esc` 关闭弹层、`Enter` 提交、方向键遍历列表 |
| 6 | 不打断用户 | 自动锁定前 10 秒给一次轻提示（Toast，可忽略），不弹模态 |
| 7 | 窄窗可用 | 320 / 400 宽下不横向滚动；表单一列；操作收进"更多"菜单 |

### 3.1 页面清单

| # | 页面 | 路由/位置 | 主任务 |
|---|---|---|---|
| 1 | 欢迎/初始化 | 全屏向导（首次） | 解释定位 + 开始 |
| 2 | 主密码设置 | 向导第 2 步 | 设置主密码 + 强度提示 |
| 3 | 恢复密钥备份 | 向导第 3 步 | 展示 + 抄写确认 |
| 4 | 解锁 | 全屏遮罩（tab 内容区） | 主密码 / 恢复密钥 |
| 5 | 首页 | 主面板 | 概览 + 快捷入口 + 最近使用 |
| 6 | 记录列表 | 主面板 | 分类/标签/收藏筛选 + 搜索 |
| 7 | 记录详情 | 抽屉/右栏 | 常用信息优先 + 按需展开秘密 |
| 8 | 新建/编辑 | 弹层（Dialog） | 类型模板表单 |
| 9 | 分类管理 | 设置内子页 | 增删改 + 影响提示 |
| 10 | 标签管理 | 设置内子页 | 同上 |
| 11 | 密码生成器 | 弹层（可从新建页调起） | 参数 + 结果 + 使用 |
| 12 | 安全设置 | 设置分区 | 锁定时间、剪贴板时间 |
| 13 | 备份与恢复 | 设置分区 | 导出/检查/导入 |
| 14 | 变更主密码 | 弹层 | 当前 + 新 + 确认 |
| 15 | 审计记录 | 设置内子页 | 只读列表 + 清空 |
| 16 | 删除保险箱 | 危险区 | 逐字确认 |

> **P1 实现差异（2026-11-18）**：P1 没有为 16 项各造独立路由，而是**一个 `VaultPanel` 工作台页面 +
> 4 个覆盖层**——`onboarding`（初始化/主密码/恢复密钥三合一流程）、`lock`（主密码/恢复密钥双 tab）、
> `home`（左筛选 rail + 中列表 + 右详情）、`editor`、`settings`（锁定与剪贴板 / 分类标签 / 安全与危险操作
> / 生成器 / 备份 / 审计 六个 tab）。这符合「单入口 + 少跳转」原则，也避免多路由把锁定态切成碎片；
> 代价是 `VaultPanel` 单文件较大（约 2000 行），P2 若继续扩张应拆为 `components/vault/` 子组件。

### 3.2 关键页面布局

**解锁页（全屏遮罩）**

```text
┌──────────────────────────────────────────────┐
│                                              │
│                 [ 锁形图标 ]                  │
│              安全保险箱已锁定                  │
│                                              │
│        ┌────────────────────────────┐        │
│        │ 主密码                   👁 │        │
│        └────────────────────────────┘        │
│              [    解 锁    ]                  │
│                                              │
│         用恢复密钥解锁（链接）                 │
│         上次锁定：闲置 5 分钟                  │
└──────────────────────────────────────────────┘
```

- 背景使用 `--surface-base` + 轻微模糊；**不显示任何记录痕迹**。
- 解锁失败：输入框下方红字，**不清空输入**（避免重输长密码），但 3 次失败后禁用 5 秒并显示倒计时。
- 恢复密钥输入：单行，自动 4 字符分组、自动大写、忽略 `-` 与空格；粘贴支持。
- 错误码映射见 [api-and-method-design.md](api-and-method-design.md) §11。

**列表页**

```text
┌ 保险箱 ────────────────────────────── 🔒 锁定 ┐
│ [搜索…            ]  [全部▾] [标签▾] [＋ 新建] │
├──────────────────────────────────────────────┤
│ ★ 某某云控制台        admin@…      3 天前   ⧉ │
│   某某论坛            user_01       2 周前  ⧉ │
│   家庭 NAS            admin         1 月前  ⧉ │
└──────────────────────────────────────────────┘
```

- 列表项**只显示 meta**（标题、用户名/邮箱、最近使用、收藏星）。
- 复制按钮（⧉）只复制**用户名**（低敏感）；密码复制必须在详情页（减少误触）。
- 锁定后列表整体替换为锁定页，**不保留骨架屏里的标题**。

**详情页**

| 区域 | 内容 | 默认 |
|---|---|---|
| 头部 | 图标 + 标题 + 类型徽标 + 收藏 | 可见 |
| 常用区 | 用户名、邮箱、站点地址（可点开浏览器） | 可见 |
| 秘密区 | 密码/密钥/恢复码，逐项"显示 / 复制" | **隐藏** |
| 折叠区 | 备注、自定义字段、创建/更新时间 | 折叠（`CollapsibleSection`） |
| 底部 | 编辑 / 删除 / 最近使用时间 | 可见 |

- 显示秘密 → 30 秒后自动回到隐藏（`setTimeout` 仅作 UI 辅助，**不作为安全机制**）。
- 复制后：`Toast "已复制，30 秒后自动清除"` + 按钮短暂变"已复制"。

### 3.3 新建/编辑表单（按类型分模板）

| 类型 | 必填 | 选填 | 说明 |
|---|---|---|---|
| 账号密码 | 标题、密码 | 用户名、邮箱、URL、平台、分类、标签、备注 | 密码行内提供"生成"按钮 |
| API 密钥 | 标题、密钥值 | 服务、到期日、说明、标签 | 值支持多行 |
| 软件许可证 | 标题、许可证/激活码 | 厂商、到期日、订单号、说明 | 到期日提醒（P3） |
| 恢复资料 | 标题、恢复码（多行） | 备用邮箱、恢复电话、说明 | 恢复码按行计数 |
| 私密备忘 | 标题、至少 1 个自定义字段 | 分类、标签、备注 | 字段可增删、拖拽排序 |
| 设备/SSH | 标题、主机、用户名、密码或私钥 | 端口、备注 | 私钥走 `blob`（base64 保真） |

- 表单**不用原生 `<select>`**（用 `Select`/`Combobox` 基元），不用 `title`（用 `data-tip`）。
- 保存：`Ctrl+Enter` 提交；关闭有未保存改动 → 二次确认（Dialog，走 overlayStack）。
- 密码字段旁提供"强度条"，文案固定："强度为启发式估计，不代表密码一定安全。"

### 3.4 密码生成器

- 弹层：长度滑块（8–64）+ 4 个类别开关 + "排除易混淆字符" + 结果框 + "重新生成" + "复制/使用"。
- 结果框默认明文（用户就是要看），但**不自动复制**、不写入历史。
- 打开时默认 20 位、四类全开、排除易混淆。

## 4. 状态设计

| 状态 | 界面 | 可用操作 | 禁止 |
|---|---|---|---|
| `noVault` | 欢迎页 | 创建 | 任何记录操作 |
| `locked` | 解锁遮罩 | 解锁 / 恢复密钥 | 列表、搜索、复制 |
| `locked(cooldown)` | 解锁遮罩 + 倒计时 | 等待 | 提交 |
| `unlocked` | 正常 UI | 全部 | — |
| `unlocked(recoveryMode)` | 顶部黄条"恢复模式：请设置新主密码" | 读、改主密码 | 新建/编辑/删除/导出 |
| `corrupt` | 错误页 + "尝试恢复密钥" | 恢复 / 删除库 | 正常读写 |
| `importing` | 进度遮罩（不可 Esc 关闭） | 取消（安全点） | 其他一切 |
| `exporting` | 进度 Toast | — | — |

**状态切换只由后端事件驱动**：前端不自行推断"应该已锁定"。

## 5. 响应式与可访问性

| 断点 | 布局 |
|---|---|
| ≥ 1100 px | 列表 + 右侧详情双栏 |
| 720–1099 px | 列表为主，详情用抽屉 |
| 400–719 px | 单列；筛选收进"筛选"按钮的 Popover |
| 320–399 px | 单列；标题两行截断；操作进"更多"菜单；表格转卡片 |

> **P1 实测（2026-11-18）**：400 px 下保险箱内容区约 174 px，列表/详情单列可用；320 px 下工作台
> 左侧导航仍固定 200 px，内容区仅 114 px，保险箱不可用。该限制来自工作台外壳，不是保险箱单页；
> P1 未修改共享外壳。达到上表 320 px 目标需外壳在极窄窗收起侧栏，或提高主窗口 `minWidth`。

- 所有尺寸用 Token（`--space-*`、`--radius-*`），不写魔法数字。
- 图标按钮必须有 `aria-label`；焦点环用 `:focus-visible`。
- 敏感字段的显示/隐藏按钮 `aria-pressed` 表达状态；复制成功用 `aria-live="polite"` 播报
  "已复制，30 秒后自动清除"（不播报内容）。
- 尊重 `prefers-reduced-motion`：锁定遮罩淡出改为瞬时。

## 6. 移动端（P2）

> 现状：`apps/mobile` 是 Expo + RN（Android），`AGENTS.md` 明确"不新增依赖须单独说明理由/体积/
> 回退并取得同意"。因此下列能力优先用**已有依赖 + 项目内原生模块**实现。

### 6.1 页面

| 页面 | 要点 |
|---|---|
| 解锁 | 大按钮"用指纹解锁"，下方"用主密码"；键盘弹起时按钮上移 |
| 列表 | 底部安全区留白；搜索框常驻顶部；左滑出现"复制/收藏" |
| 详情 | 全屏；秘密默认隐藏，点击"按住显示"（按住才显示，松手即隐藏） |
| 新建 | 分步表单（第 1 步基本信息，第 2 步秘密） |
| 设置 | 自动锁定、生物识别开关、备份 |

### 6.2 生物识别

| 项 | 设计 |
|---|---|
| 依赖 | `expo-local-authentication`（若未安装需单独申请）；密钥存 `expo-secure-store` |
| 密钥关系 | 生物识别**只是解锁已存"设备密钥"的快捷方式**；设备密钥再由 ECDH/信封解 DEK（P2）；**生物特征永不出设备、不进 Task Dock** |
| 失败降级 | 生物识别失败 3 次 → 只能用主密码；**不允许生物识别成为唯一入口** |
| 关闭 | 设置里可关闭；关闭即删 SecureStore 中的设备密钥 |
| 平台限制 | Android 生物识别仅证明"设备主人"；root/越狱设备不承诺安全，设置页显示"设备可能不安全"提示 |

### 6.3 后台与截屏

| 事件 | 动作 |
|---|---|
| `AppState` 变 `background` | **立即**锁定（移动端无"复制到浏览器"的宽限需求，安全优先） |
| 返回前台 | 显示解锁页 |
| 截屏防护 | Android 需 `FLAG_SECURE`（项目内原生模块，P2 实现）；**未实现前**在详情页显示"请勿截屏"提示，并明确"当前无法阻止截屏" |
| 最近任务缩略图 | `FLAG_SECURE` 同时隐藏；未实现前退出时先遮罩 |

### 6.4 触控规范

- 最小点击区 44×44 dp；复制按钮在拇指可达区（右侧下 1/3）。
- 长按字段 → 菜单（复制/显示），不触发系统文本选择菜单（`selectable={false}`）。
- 单手：新建流程的"下一步"固定在底部，不随内容滚动。

## 7. 视觉规范（新增的最小集）

| 元素 | 规则 |
|---|---|
| 锁定遮罩 | `--surface-overlay` + 8 px 模糊；图标 48 px；标题 `--text-lg` |
| 敏感区 | 折叠容器左侧 2 px `--border-accent` 竖线；展开后不变色（避免"高亮=重要"的误导） |
| 复制反馈 | 复用现有 Toast；成功 `StatusBadge tone=success`；清除失败 `tone=warning` |
| 危险操作 | 删除库用 `tone=danger` 文本按钮 + 逐字确认，不用大红色块（降低误触恐慌） |
| 图标 | 复用现有图标集；无"盾牌"新图标则用现有 `lock`/`key` |

**禁止**：为保险箱引入新的圆角/阴影/字体；禁止自造色板。
