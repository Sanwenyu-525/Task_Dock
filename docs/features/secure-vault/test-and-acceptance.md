## 3. T-CRY：加密

| ID | 用例 | 方法 | 期望 |
|---|---|---|---|
| T-CRY-01 | 相同明文两次加密 | 对同一 payload 调两次 `encrypt_record` | 两个 `ct` 与 `nonce` 均不同；都能解回原文 |
| T-CRY-02 | 密文篡改 | 翻转 `meta_ct` 任意 1 bit | `open` 失败 → `VAULT_DATA_CORRUPT` |
| T-CRY-03 | 错误主密码 | 用错口令解锁 | 失败，且 `fail_count+1`；不返回任何记录 |
| T-CRY-04 | 跨记录搬移 | 把 A 的 `meta_ct` 写到 B 的 `id` 下 | 解密失败（AAD 含 id） |
| T-CRY-05 | 跨用途搬移 | 把 `secret_ct` 放进 `meta_ct` 列 | 解密失败（AAD 含 purpose） |
| T-CRY-06 | nonce/密钥复用检查 | 静态扫描 + 运行时断言：同一 `(id,purpose,dek_ver)` 的子密钥只出现 1 次 | 无复用 |
| T-CRY-07 | 版本识别 | 构造 `alg_ver=2` / `data_ver=9` 的载荷 | `VAULT_FORMAT_UNSUPPORTED`，不"尽力解析" |
| T-CRY-08 | 参数升级 | 旧信封 `m=32MiB`，基线 `64MiB` → 解锁后重封装 | 新信封参数=基线；DEK 不变；记录可读 |
| T-CRY-09 | HKDF 域分离 | 逐字比对 `info` 常量与文档 §4.2 | 完全一致（字符串断言） |
| T-CRY-10 | NFKC 归一 | 全角/半角、首尾空格不同的等价口令 | 派生出同一 KEK |

**实现要点**：T-CRY-01/04/05 必须在 `cfg(test)` 内直接调 `crypto`，不经 IPC；T-CRY-06 用
`grep` 检查所有 `HKDF` 调用点的 `info` 拼接。

## 5. T-LOCK：锁定

| ID | 用例 | 方法 | 期望 |
|---|---|---|---|
| T-LOCK-01 | 闲置超时 | 设 60 s，静置 | 60±5 s 内锁定；事件 reason=idle |
| T-LOCK-02 | 后台宽限 | 设 30 s，切走窗口 | 30±5 s 锁定；切回需解锁 |
| T-LOCK-03 | 窗口隐藏 | 点关闭（到托盘） | **立即**锁定（不等宽限） |
| T-LOCK-04 | 系统锁屏 | 真机 Win+L | 立即锁定（WTS 事件） |
| T-LOCK-05 | 休眠/唤醒 | 真机睡眠 30 s 后唤醒 | 唤醒后处于锁定；若时钟间断 ≥10 s 也锁 |
| T-LOCK-06 | 锁定后 UI | 锁定后截图 | 无标题/账号/分类名闪现（含 100 ms 内） |
| T-LOCK-07 | 并发绕过 | 解锁瞬间并发 20 个 `record_get` + 一次 `lock` | 所有在飞请求返回后，后续请求全部 `VAULT_LOCKED`；无"锁后返回明文" |
| T-LOCK-08 | 冷却 | 连续错 6 次 | 第 3/4/5/6 次分别进入 5/30/120/300 s 冷却；重启后仍生效 |
| T-LOCK-09 | 定时器唯一性 | 解锁/锁定 100 次 | 只有 1 个 ticker 任务（`tokio` 任务数不增长） |

**T-LOCK-04/05 必须真机**：jsdom/CDP 不能证明 WTS 与电源事件。

## 14. 验收判定

| 结论 | 条件 |
|---|---|
| **通过** | 阻断项全通过；非阻断项失败 ≤ 2 且已记录风险与修复计划 |
| **部分通过** | 阻断项全通过；非阻断项失败 3–6 |
| **不通过** | 任一阻断项失败 |
| **证据不足** | 缺命令/退出码/证据路径，或未在指定构建上执行 |
| **ENVIRONMENT BLOCKED** | 锁屏/休眠/权限/磁盘等环境原因无法执行；**不计通过，不判代码缺陷** |

**阻断项清单**：`T-CRY-02/03/04/05`、`T-DATA-01/02/03/08`、`T-LOCK-03/04/06/07`、
`T-CLP-03/04`、`T-REC-01/02/04/06`、`T-BKP-02/03/04/05/06`、`T-ISO-01..05`、`T-SRCH-03`。

### P1 Gate（12 条，全过才可发 MVP）

1. 主密码建库 + 解锁 + 锁定可用
2. 恢复密钥可恢复，且旧密钥在重生成后失效
3. 改主密码后记录 `rev` 不变（零重写）
4. 库/备份/日志/搜索四处无明文哨兵
5. 锁屏/休眠/隐藏/闲置/后台五类锁定全部生效
6. 剪贴板自动清除 + 用户覆盖保护
7. 加密备份导出/检查/导入 + 失败不写库
8. 五条隔离路径全部拒绝
9. 1000 条记录性能达标
10. 错误码分类完整（§api 11 全部可达）
11. 导航/路由/设置注册契约通过
12. 报告齐备（含未验证项与环境阻塞）
