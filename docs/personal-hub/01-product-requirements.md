## 1. 产品定位

TaskDock Personal Hub 是**安全优先的个人设备中枢、加密组网与远程控制系统**。第一阶段以 Windows 电脑为个人服务器、Android 手机为主要接入设备。用户无需了解公网 IP / NAT / VPN / WireGuard / 端口映射。

**最高原则：安全第一 > 稳定性 > 易用性 > 功能丰富度。** 不得为开箱即用降低身份验证、设备授权、通信加密、本地安全认证要求。

---

## 2. 理想使用流程（规格 §1）

1. PC 点击「启用 Personal Hub」→ 启动独立普通用户进程 Hub（基线 D2）。
2. 电脑展示配对二维码 → Android 扫码 → PC 本机批准 → 双向身份指纹确认。
3. 手机通过云端发现与 WebRTC P2P/TURN 加入私有加密覆盖通道 → 访问授权服务（D5/D6）。
4. 远程控制时被控端必须通过本机系统凭据认证（D9）。
5. 直连失败自动尝试 TURN 中继（D7）。

**约束（基线 D1/D12）**：v1.0 为 PC-first，不支持脱离电脑的手机 A↔手机 B 独立组网/互控；仅预留接口，不得提前实施。

## 3. 核心需求清单（按优先级）

### P0 — 强制本机凭据认证（最重要，基线 §8）
- 每次新建远控会话，被控端必须在本机验证该设备自己的系统凭据，不因配对/授权/连接而跳过（D9）。
- Android：默认 `DEVICE_CREDENTIAL`（PIN/锁屏密码/图案），系统 UI；生物识别非默认，需用户显式选项；不读取/保存/传输锁屏密码（§5.3）。
- Windows：Windows Hello / 设备 PIN（真实 HWND interop）；系统凭据不可用时**关闭 Windows 远控并报告阻塞**，不退化 App PIN（§4.2）。
- 认证结果仅本机转换成一次性短时 grant（≤60s，绑定 controller/target/session/nonce/scopes）；失败/取消/超时/不支持即拒绝（D11）。
- 严格失败关闭：控制端不能远程输入被控端系统密码替代本机认证；无人值守无法认证则拒绝。

### P0 — 每次远控独立授权（规格 §2.2）
- 区分配对/入网/文件/屏幕/触摸/键盘/剪贴板/音频/设备管理，能力级独立授权。
- 会话请求含 controller/target/session/权限/nonce/过期/签名/防重放。
- 授权一次性、短时、绑定控制端与会话、不可跨设备复用。

### P0 — 强制安全状态机（规格 §2.3）
- 12 态状态机；任何失败进入安全失败态；不得异常跳过认证。

### P1 — 设备身份与配对（基线 §6）
- 首次运行本地生成 Ed25519 身份密钥；私钥 DPAPI / Android Keystore 包装，云端只有公钥；**v1.0 不生成 WireGuard 密钥**（§6.1）。
- 二维码含协议版本/控制面地址/invitation_id/128-bit secret/nonce/过期/Hub 指纹/签名；5 分钟一次性、最多 5 次错误尝试；不含私钥/令牌/永久授权/密码。
- 双向身份指纹确认 + **PC 本机批准**；远程分享二维码也不能绕过 PC 批准；防 MITM。

### P1 — 网络（基线 §4/§7，D5）
- PersonalHubService 独立普通用户进程；桌面 UI 只经当前用户 ACL 的 Named Pipe 管理；禁止无鉴权 localhost HTTP。
- **v1.0 使用 WebRTC 应用层加密覆盖，不安装系统级 WireGuard VPN、不分配虚拟网卡 IP、不接管全部流量**；禁止自研加密协议。
- 连接优先级：LAN 本地 HTTPS > WebRTC P2P（STUN）> TURN 中继（UDP→TCP/TLS 443）；失败自动回退。
- TaskDock 云端只做注册/信令/发现/撤销/限流；TURN 短时凭证、只转密文；不持私钥、不签发授权。

### P1 — 远控系统（规格 §5）
- 屏幕与操作分开：Android MediaProjection + AccessibilityService；Windows 受限桌面捕获 + 输入接口 + 安全桌面保护。
- WebRTC 视频 + 加密 DataChannel；独立 session/序号/防重放。
- 开始提示/持续状态/停止按钮/一键撤销/中断关闭/超时撤销/高风险再认证。

### P1 — 数据安全（规格 §6）
- 威胁模型覆盖 15 项风险；端到端身份验证、加密、密钥轮换、防重放、撤销、最小权限、本地认证、审计、异常断开、限流、安全失败关闭。
- 禁记密码/私钥/完整令牌/生物特征/可复用凭证。

---

## 4. 非目标（第一阶段严格模式）

- 不支持无人值守远控（需本机认证）。
- 不默认全流量走云端。
- 不暴露 ADB/scrcpy 公网；不为兼容关闭 TLS/WebRTC DTLS。
- 不删除现有功能规避架构冲突。
- 未真实网络测试不声称跨城市连接成功。

基线 §2.2 明确不做：手机↔手机脱离 PC 组网；通用 IP VPN/虚拟网卡/全局接管；公网暴露 ADB/scrcpy/RDP/SSH/本地 HTTP；无人值守远控/静默解锁/绕过锁屏；远程输入被控端系统密码；远控 Windows 安全桌面/UAC/登录界面；云端保存录像/密码/私钥/会话内容。

必须区分：**已实现 / 已构建 / 已单元测试 / 已集成测试 / 已真实设备测试 / 未验证**，不虚报。
