# ADR-0001：安全第一与本机认证强制门槛

- 日期：2026-11-19
- 状态：Accepted（源自用户规格最高原则，非新决策）
- 关联：[07-local-auth-design.md](../07-local-auth-design.md)、[06-threat-model.md](../06-threat-model.md)

## Context

Personal Hub 涉及用户电脑、手机、网络身份、系统权限、远程控制和个人数据，安全等级高于普通业务功能。存在「为开箱即用降低认证」的诱惑（如无人值守远控、扫码即远控）。

## Decision

1. 优先级固定为 **安全 > 稳定 > 易用 > 功能**。
2. **本机系统身份认证是远程控制的强制门槛**：每次新会话被控端必须本机认证，不因配对/授权/隧道跳过。
3. 第一阶段严格模式：控制端不能远程输入被控端系统密码；无人值守无法认证则拒绝会话。
4. 任何认证失败/权限不足/超时/身份不匹配 → 安全失败态，不通过异常跳过。

## Consequences

- 牺牲无人值守远控的可用性；未来若有该需求，须独立威胁模型 + 独立授权 + 额外认证，不改变默认策略。
- P5 本机认证通过前不得开发或启用 P6 远程输入控制通道（基线 §14 阶段门）。
- 产品文案必须说明本地认证要求与设备被攻陷时的剩余风险（R0）。
