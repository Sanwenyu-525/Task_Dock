## 5. 执行与证据规则

- 真机/网络/性能按 `docs/ACCEPTANCE_ROUTING.md` A–F 通道；物理操作最后手段并授权。
- 证据放 `tmp/acceptance/personal-hub-<项>/`，含命令/时间/退出码/脱敏元数据；归档 `docs/` 并更新索引。
- 环境阻塞写 `ENVIRONMENT BLOCKED`，不标记通过；证据不足写「证据不足」。
- 结论只用 **通过 / 部分通过 / 不通过 / 证据不足**。
- 安装/升级/卸载、系统服务安装未经授权不执行并写「未执行」。

- Windows 系统凭据在本机确认不可用时：Windows 远控标 BLOCKED 并提交原始证据，不因此降低其它链路安全标准、不退化 App PIN。
- 阶段 8 门：全部 P/A/S/N 真机执行 + 安全回归，出具完整测试报告与剩余风险。
