## 4. 本轮发现并修复的真实缺陷

1. **备份整体不可读（既有缺陷）**：`transfer_contents/transfer_items/transfer_batches/entity_links`
   在 `BACKUP_TABLES` 中声明为扩展表，却未登记进 `EXTENDED_TABLES`，导致任何全量/快速备份
   读取都被判定「缺少扩展数据表」，恢复链路整体失效。已补登记，并为 `recent` 策略补通用
   SQL 分支。回归：`planning_tables_roundtrip_in_full_and_quick_backup` 由失败转为通过。
2. **资产计数口径错误**：读端把剪贴板资产计数与「全部资产文件」比较，暂存架/语音/协作资产
   一并计入，导致计数校验必然失败。已按命名空间分别校验。
3. **组件 ID 跨页重名**：前端按页面各自编号（两页都可能出现 `c1`），后端按页校验选择项时
   会把合法选择判成「组件不属于该页」，AI 修改命中错组件。已改为全文档唯一编号，
   后端新增跨页重名拒绝。
4. **保存后跳回第一页并清空选中**：原型编辑器在 `doc.revision` 变化时重置 `activeId/selectedId`，
   保存后连续编辑被打断、「AI 修改选中组件」失去目标。已改为保留仍然有效的页面与选中组件。
5. **AI 修改基于未保存内容**：AI 提案读取的是后端已保存版本，未保存的新组件不在其中，
   生成会报「选中组件不属于该页面」。现在编辑器在有未保存改动时明确提示先保存。
