# 05 · 数据模型与接口规范

## 1. 迁移

- 版本：**v77**（当前最大 v76 = `agent_access::schema::MIGRATION_76`，见 `db/mod.rs:2117-2119`）。
- DDL 位置：`src-tauri/src/collab/schema.rs`，`pub const MIGRATION_77: &str`。
- 登记：`db/mod.rs` 的 `MIGRATIONS` 末尾追加一行；`BACKUP_TABLES` 追加 9 张表。
- 纯新增表，无 `ALTER`、无数据回填；失败自动回滚；旧库升级后新表为空。
- 不修改任何既有表/列/索引；不改 `planning_*`、`tasks` 语义。
- 回滚策略：停止使用新表即可；表保留不删（不执行破坏性 `DROP`）。

## 2. 实体关系

```
planning_projects (既有)
 ├── collab_issues (kind=feature/bug/...)
 │    ├── collab_issue_links (issue↔issue / issue↔plan)
 │    └── collab_evidence (subject=issue/bug/task/plan/visual)
 ├── collab_plans
 │    ├── collab_plan_links (plan↔issue / visual / task / feature)
 │    ├── collab_visual_docs
 │    │    └── collab_visual_versions
 │    └── collab_ai_jobs
 └── collab_audit（按 project 维度）
tasks (既有)
 └── collab_plan_links(kind=task)   ← 只记录方案→任务，不复制任务字段
```

不建立跨表外键到 `tasks`（既有表无稳定级联语义），用 `collab_plan_links` 弱关联 + 事务保证；
读取时若任务已删除，进度计数跳过并标注 `orphan`。

## 3. 表结构（v77 DDL）

```sql
-- 1) 需求与 Bug（统一实体，kind 区分；Bug 额外字段可空）
CREATE TABLE collab_issues (
  id TEXT PRIMARY KEY NOT NULL,
  project_id TEXT NOT NULL REFERENCES planning_projects(id) ON DELETE CASCADE,
  kind TEXT NOT NULL CHECK (kind IN
    ('feature','improvement','architecture','performance','security','tech_debt','bug','other')),
  title TEXT NOT NULL,
  description TEXT NOT NULL DEFAULT '',
  impact TEXT NOT NULL DEFAULT '',              -- 影响范围
  priority TEXT NOT NULL DEFAULT 'P2' CHECK (priority IN ('P0','P1','P2','P3')),
  status TEXT NOT NULL DEFAULT 'open' CHECK (status IN
    ('open','triaged','in_progress','resolved','verified','closed','archived')),
  acceptance TEXT NOT NULL DEFAULT '',          -- 验收要求
  repro_steps TEXT NOT NULL DEFAULT '[]',       -- JSON string[]，Bug 用
  expected_result TEXT,                         -- Bug
  actual_result TEXT,                           -- Bug
  environment TEXT,                             -- Bug
  related_files TEXT NOT NULL DEFAULT '[]',     -- JSON string[]
  resolution TEXT NOT NULL DEFAULT '',          -- 解决说明
  assignee TEXT NOT NULL DEFAULT '',
  dedupe_key TEXT NOT NULL DEFAULT '',          -- normalize(title)+kind
  source_agent TEXT NOT NULL DEFAULT '',
  source_session TEXT NOT NULL DEFAULT '',
  source TEXT NOT NULL DEFAULT 'ui'
    CHECK (source IN ('ui','cli','mcp','rest','file','system','ai')),
  revision INTEGER NOT NULL DEFAULT 1,
  created_by TEXT NOT NULL DEFAULT '',
  updated_by TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX idx_collab_issues_project_status ON collab_issues(project_id, status, updated_at);
CREATE INDEX idx_collab_issues_project_kind   ON collab_issues(project_id, kind, updated_at);
CREATE INDEX idx_collab_issues_dedupe        ON collab_issues(project_id, dedupe_key);
CREATE INDEX idx_collab_issues_source         ON collab_issues(source_agent, source_session);

-- 2) 实体关联（issue↔issue / issue↔plan）
CREATE TABLE collab_issue_links (
  id TEXT PRIMARY KEY NOT NULL,
  issue_id TEXT NOT NULL REFERENCES collab_issues(id) ON DELETE CASCADE,
  target_kind TEXT NOT NULL CHECK (target_kind IN ('issue','plan')),
  target_id TEXT NOT NULL,
  relation TEXT NOT NULL CHECK (relation IN ('related','duplicate','blocks','caused_by')),
  created_by TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  UNIQUE(issue_id, target_kind, target_id, relation)

CREATE INDEX idx_collab_issue_links_target ON collab_issue_links(target_kind, target_id);

-- 3) 证据（文件复制入库；仅存元数据 + 受控路径 + 哈希）
CREATE TABLE collab_evidence (
  id TEXT PRIMARY KEY NOT NULL,
  project_id TEXT NOT NULL REFERENCES planning_projects(id) ON DELETE CASCADE,
  subject_kind TEXT NOT NULL CHECK (subject_kind IN ('issue','bug','plan','task','visual')),
  subject_id TEXT NOT NULL,
  kind TEXT NOT NULL CHECK (kind IN
    ('screenshot','log','stack','video','report','test','other')),
  title TEXT NOT NULL DEFAULT '',

  sha256 TEXT NOT NULL,
  size_bytes INTEGER NOT NULL,
  mime TEXT NOT NULL DEFAULT '',
  meta_json TEXT NOT NULL DEFAULT '{}',
  created_by TEXT NOT NULL DEFAULT '',
  source TEXT NOT NULL DEFAULT 'ui'

  created_at TEXT NOT NULL,
  UNIQUE(project_id, sha256, subject_kind, subject_id)

CREATE INDEX idx_collab_evidence_subject ON collab_evidence(subject_kind, subject_id, created_at);

-- 4) 方案
CREATE TABLE collab_plans (
  id TEXT PRIMARY KEY NOT NULL,
  project_id TEXT NOT NULL REFERENCES planning_projects(id) ON DELETE CASCADE,
  issue_id TEXT REFERENCES collab_issues(id) ON DELETE SET NULL,
  title TEXT NOT NULL,
  summary TEXT NOT NULL DEFAULT '',
  solution_md TEXT NOT NULL DEFAULT '',
  breakdown_json TEXT NOT NULL DEFAULT '[]',   -- 任务草案 [{title,description,priority}]
  status TEXT NOT NULL DEFAULT 'draft' CHECK (status IN

  review_note TEXT NOT NULL DEFAULT '',
  approved_by TEXT NOT NULL DEFAULT '',
  approved_at TEXT,
  revision INTEGER NOT NULL DEFAULT 1,
  created_by TEXT NOT NULL DEFAULT '',
  updated_by TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX idx_collab_plans_project_status ON collab_plans(project_id, status, updated_at);
CREATE INDEX idx_collab_plans_issue ON collab_plans(issue_id);

-- 5) 方案关联
CREATE TABLE collab_plan_links (

  target_kind TEXT NOT NULL CHECK (target_kind IN ('issue','visual','task','feature')),
  target_id TEXT NOT NULL,
  created_at TEXT NOT NULL,
  UNIQUE(plan_id, target_kind, target_id)
);
CREATE INDEX idx_collab_plan_links_target ON collab_plan_links(target_kind, target_id);

-- 6) 可视化文档
CREATE TABLE collab_visual_docs (
  id TEXT PRIMARY KEY NOT NULL,

  plan_id TEXT REFERENCES collab_plans(id) ON DELETE SET NULL,
  title TEXT NOT NULL,
  description TEXT NOT NULL DEFAULT '',
  kind TEXT NOT NULL CHECK (kind IN
    ('flowchart','architecture','dataflow','prototype','bug_annotation','static_image','diff')),
  schema_version INTEGER NOT NULL DEFAULT 1,
  source_format TEXT NOT NULL CHECK (source_format IN ('json','mermaid','image','svg')),
  source_content TEXT NOT NULL DEFAULT '{}',
  renderer TEXT NOT NULL,
  preview_asset TEXT,
  status TEXT NOT NULL DEFAULT 'draft' CHECK (status IN ('draft','published','archived')),
  version INTEGER NOT NULL DEFAULT 1,
  revision INTEGER NOT NULL DEFAULT 1,
  created_by TEXT NOT NULL DEFAULT '',
  updated_by TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX idx_collab_visual_project ON collab_visual_docs(project_id, kind, updated_at);
CREATE INDEX idx_collab_visual_plan ON collab_visual_docs(plan_id);

-- 7) 可视化版本（只增不减）
CREATE TABLE collab_visual_versions (
  id TEXT PRIMARY KEY NOT NULL,
  document_id TEXT NOT NULL REFERENCES collab_visual_docs(id) ON DELETE CASCADE,
  version INTEGER NOT NULL,
  snapshot_json TEXT NOT NULL,
  change_summary TEXT NOT NULL DEFAULT '',
  created_by TEXT NOT NULL DEFAULT '',
  source TEXT NOT NULL DEFAULT 'ui'
    CHECK (source IN ('ui','cli','mcp','rest','file','system','ai')),
  created_at TEXT NOT NULL,
  UNIQUE(document_id, version)
);

-- 8) AI 任务（文本/图像；状态持久化，失败可查）
CREATE TABLE collab_ai_jobs (
  id TEXT PRIMARY KEY NOT NULL,
  project_id TEXT NOT NULL REFERENCES planning_projects(id) ON DELETE CASCADE,
  plan_id TEXT REFERENCES collab_plans(id) ON DELETE SET NULL,
  document_id TEXT REFERENCES collab_visual_docs(id) ON DELETE SET NULL,
  kind TEXT NOT NULL CHECK (kind IN ('text','image')),
  provider TEXT NOT NULL,
  model TEXT NOT NULL DEFAULT '',
  prompt TEXT NOT NULL,
  params_json TEXT NOT NULL DEFAULT '{}',
  status TEXT NOT NULL CHECK (status IN

  result_json TEXT,
  error_code TEXT,
  error_message TEXT,
  cost_units REAL NOT NULL DEFAULT 0,
  created_by TEXT NOT NULL DEFAULT '',
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);
CREATE INDEX idx_collab_ai_jobs_project ON collab_ai_jobs(project_id, status, created_at);

-- 9) 审计（只增不改）
CREATE TABLE collab_audit (
  id TEXT PRIMARY KEY NOT NULL,
  project_id TEXT NOT NULL,
  entity_kind TEXT NOT NULL,
  entity_id TEXT NOT NULL,
  action TEXT NOT NULL,
  actor TEXT NOT NULL,
  actor_kind TEXT NOT NULL,
  source TEXT NOT NULL,
  revision_before INTEGER,

CREATE INDEX idx_collab_audit_entity ON collab_audit(entity_kind, entity_id, created_at);
CREATE INDEX idx_collab_audit_project ON collab_audit(project_id, created_at);
```

## 4. 关键约束与语义

1. `collab_issues.dedupe_key` 只用于**提示**，不建唯一索引；重复允许存在（人工决定合并）。
2. `collab_evidence` 唯一键防止同证据重复入库；不同 subject 引用同一文件时按 subject 各存一行（路径可同）。
3. `collab_plans.status` 只由服务层状态机修改；`approved` 必须有 `approved_by/approved_at`。
4. `collab_visual_docs.version` 从 1 开始，每次内容写入 +1；`revision` 为乐观锁。
5. `collab_audit` 不接受 Agent 写/删；只在服务层事务内插入。
6. 所有时间 `RFC3339` 本地带偏移字符串（与既有 `now_iso()` 语义一致）。
7. 项目删除（`planning_projects` DELETE）级联删除本模块表；归档不删除。

## 6. MCP 工具

命名与既有 `taskdock_*` 一致；`write=true` 的工具走授权 + 审计 + revision。

| 工具 | 能力 | 说明 |
|---|---|---|
| `taskdock_get_project_context` | plans.read | 上下文（scope/fields/page） |
| `taskdock_list_issues` | plans.read | 需求/Bug 列表 |
| `taskdock_get_issue` | plans.read | 详情（关联/证据） |
| `taskdock_create_issue` | plans.write | 8 类 kind；返回重复候选 |
| `taskdock_create_bug` | plans.write | Bug 专用字段 |
| `taskdock_update_issue` | plans.write | 必须 `expected_revision` |
| `taskdock_attach_evidence` | plans.write | path 或 text；大小限制 |
| `taskdock_detect_duplicates` | plans.read | 只提示 |
| `taskdock_resolve_bug` | plans.write | 解决说明 |
| `taskdock_create_plan` | plans.write | from issue_id |
| `taskdock_update_plan` | plans.write | 必须 revision |
| `taskdock_submit_plan` | plans.write | draft→in_review |
| `taskdock_generate_visualization` | plans.write | 返回 job/文档 |
| `taskdock_modify_visualization` | plans.write | 结构化 ops |
| `taskdock_get_visualization` | plans.read | 文档 + 版本 |
| `taskdock_create_prototype` | plans.write | 原型文档 |
| `taskdock_get_prototype` | plans.read | 原型 + 状态默认 |
| `taskdock_create_tasks_from_plan` | plans.write | 仅 approved；幂等 |
| `taskdock_upload_evidence` | plans.write | 同 attach_evidence |

`taskdock_delete_*`。审批与关闭只能 UI。

## 9. 错误码

| code | category | 触发 |
|---|---|---|
| `VALIDATION` | validation | 字段长度/枚举/JSON/坐标/上限 |
| `NOT_FOUND` | not_found | 项目/实体/版本/任务不存在 |
| `PERMISSION_DENIED` | permission | 能力不足、跨项目、Agent 审批 |
| `CONFLICT` | conflict | revision 不匹配、非法状态转换 |
| `DUPLICATE_PLAN` | conflict | 同一 Issue 重复创建方案 |
| `PROVIDER_UNAVAILABLE` | unsupported | 未配置模型/图像 provider |
| `UNSUPPORTED` | unsupported | 不支持的 renderer/导出格式 |
| `DATABASE_ERROR` | database | SQLite 失败（detail 只含错误码） |
| `OVERLOADED` | service | 队列/并发上限（后续） |
