## 7. 测试矩阵

### 7.1 单元测试（Rust，`collab/tests.rs`）

- Issue：创建/更新/归档/分页/字段过滤/非法 kind/超长/跨项目。
- Bug：复现步骤 JSON/去重/解决/验证/无证据/Agent 越权。
- Plan：创建重复/状态转换矩阵（8 状态 × 允许边）/Agent 审批拒绝/任务拆解幂等/进度空分母。
- Visual：7 类校验/版本单调/恢复/ diff 计数/安全字符/导出 SVG。
- Prototype：六类 patch/坐标上限/事件目标/状态机五动作/循环检测。
- AI：provider 未配置/本地生成 schema 通过/失败记录。
- Evidence：大小/扩展名 sha 幂等/路径逃逸。

### 7.2 集成测试

- MCP 创建 Issue → `collab_list_issues` 可见。
- MCP 创建 Bug → 上传证据 → 解决 → UI 验证。
- 方案批准 → 拆解任务 → `tasks` 表可见 → 进度正确。
- 版本创建 → 对比 → 恢复 → 版本号 +1。
- IPC 与 MCP 对同一操作返回一致结构（同 service）。

### 7.3 安全测试

- Agent 无能力/跨项目/审批/删除全部拒绝。
- 原型含 `<script>`、`javascript:`、`onclick=`、`http://` 图片 → 拒绝。
- 证据路径 `../../` → 拒绝；超大文件 → 拒绝。
- 并发两次更新同一 revision → 一次成功一次 CONFLICT。
- 审计行不能被 Agent 删除（无接口）。

### 7.4 UI 验收

- 空状态/加载/错误/长文本；320/400/640 宽度；深/浅主题；Escape/焦点。
- 图节点点击、缩放、灯箱；原型 Tab/弹窗/开关/输入；版本 diff；证据预览。
- 真实窗口走查记录写入 `tmp/acceptance/collab-center/report.md`。
