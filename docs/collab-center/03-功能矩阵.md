# 03 · 功能矩阵

> **唯一 ID 规则**：`AC-<两位序号>`，创建后永不复用、永不删除条目。未实现的功能保留条目并把状态
> 改为「未开始/受阻」，不允许通过删除条目掩盖未完成。
> 状态：`未开始` / `开发中` / `部分完成` / `完成（代码+测试）` / `已验收` / `受阻`。
> 优先级：P0 本轮必须；P1 本轮尽量；P2 后续。
>
> **2026-11-18 状态回填**：`完成（代码+测试）` 表示代码已实现且有 `src-tauri/src/collab/tests.rs` 中
> 至少一个真实执行的测试覆盖；`部分完成` 表示代码已落地但测试覆盖或真实 UI 验收不完整；`受阻` 表示
> 依赖并行任务拥有的文件；`已验收` 表示已在真实 WebView2 页面完成该功能的主路径操作并留存截图/证据。
> 统计：45 项，其中完成（代码+测试）14 项、已验收 12 项、部分完成 14 项、未开始 3 项、受阻 2 项、
> 开发中 0 项。2026-11-18 第二轮真实 UI 验收新增 AC-09、AC-24、AC-25、AC-27 为「已验收」。
