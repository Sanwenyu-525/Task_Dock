# 07 · 安全与性能规范

> 适用：`collab` 模块的 IPC / MCP（以及后续 CLI/REST）、可视化渲染、原型、证据、AI 生成。
> 原则：**默认拒绝、最小权限、不可信内容只做数据、失败关闭、可审计**。

## 1. 威胁模型

| 威胁 | 入口 | 影响 | 对策 |
|---|---|---|---|
| 外部 Agent 越权读写其他项目 | MCP/REST | 数据泄露/篡改 | 项目授权 + 能力校验 + 服务端推导 actor |
| Agent 自批方案/自行关闭 Bug | MCP | 绕过人工审批 | 审批/验收仅 UI Actor；MCP 无对应工具 |
| 恶意原型执行脚本 | 可视化内容 | 主应用 XSS/命令执行 | 不执行 JS/HTML；白名单 DSL；禁止 eval/innerHTML |
| 证据路径逃逸 | 上传 | 读取任意本地文件 | 只允许普通文件 + 应用数据目录；拒绝 `..`/符号链接 |
| AI 返回恶意/超限内容 | 生成 | 注入/卡死 | Schema 校验 + 长度/数量上限 + 禁止 HTML/URL |
| 并发覆盖 | 多 Agent | 丢修改 | revision 乐观锁；冲突返回当前版本 |
| 审计被篡改 | 任意 | 无法追责 | 审计只由服务层插入；MCP 无删除接口 |
| 模型密钥泄露 | 配置 | 费用/数据风险 | 密钥只进 DPAPI 存储；不下发前端/日志 |
| 大文件/大图卡死 UI | 证据/可视化 | 内存/CPU | 大小、节点数、组件数、文本长度硬上限 |

## 2. 外部 Agent 身份认证

- **MCP**：复用 `mcp/auth.rs` 的 Agent 行 + token；`collab_tools` 不解析自报身份，只读 `ctx.agent`。
- **CLI**：本机进程视为 `local`（等价 UI 权限），但写操作仍写审计；`TASKDOCK_CLI_READONLY=1`
  强制只读（由 agent_access 入口执行，本模块不重复判断）。
- **REST**：Bearer token（agent_access）；仅 loopback，远程默认关闭。
- **禁止**：请求体中的 `actor`/`source`/`agent_id` 一律忽略；来源由入口判定。
- 过期凭证、禁用 Agent、撤销授权：每次调用实时查表，不缓存授权结果。

## 3. 项目级权限

- 能力（Capability）→ 接口映射见 `04-技术架构.md` §8。
- Agent 额外要求 `mcp_agent_grants(agent_row_id, project_id)` 命中；`readonly` scope 只能读。
- 跨项目：任何实体读取前校验其 `project_id` 与请求项目一致；不一致返回 `PERMISSION_DENIED`，
  不泄露实体是否存在（统一错误文案）。
- 审批：`review_plan` 内部硬判断 `actor.kind == Ui`，即使未来新增能力也不授予 Agent。
- 删除：本轮不提供删除命令；归档保留数据。

## 4. 原型运行沙箱

**首选结构化渲染（本轮实现）**：
- 组件类型白名单：`frame,text,heading,button,input,switch,tabs,list,image,badge,divider,chart`。
- 样式白名单键：`bg/fg/radius/fontSize/fontWeight/padding/gap/align/border`；值形态限定
  `var(--token)`、`#hex`、`Npx`、数字、枚举；拒绝 `url(`、`expression(`、`javascript:`、`@import`。
- 事件白名单：`navigate/openModal/closeModal/toggle/setValue`；目标必须存在于文档。
- 前端不使用 `dangerouslySetInnerHTML`、`eval`、`new Function`、`innerHTML`；组件由 React 元素映射。
- 图片：只允许后端返回的应用内 asset；禁止 `http(s)://`、`data:`（防大 payload）、`file://`。

**若未来支持 HTML/JS（本轮不做）**：
- 独立 WebView 或 `sandbox` iframe（无 `allow-same-origin`），严格 CSP（`default-src 'none';
  img-src asset:; style-src 'unsafe-inline'`），postMessage 白名单，独立进程/独立数据目录，
  禁止 Tauri API、禁止本地文件、网络默认关闭，执行超时 5s、内存上限 256MB。
- 未实现前不得提供「运行 HTML 原型」入口。

## 5. AI 生成内容校验

1. 输出必须是 JSON（不接受 Markdown 代码块直接入库；解析失败即失败）。
2. `visual::validate`：kind 白名单、节点/边/页/组件/文本上限、引用完整性、坐标范围。
3. `prototype::validate`：组件/样式/事件白名单；事件目标存在。
4. 禁止字段：`html`、`script`、`iframe`、`src`（外部）、`eval`。
5. 失败：`collab_ai_jobs.status=failed` + `error_code/error_message`；**不生成文档、不显示成功**。
6. 生成结果与用户输入分离：模型不能直接写数据库；只返回候选，由 service 校验后落库。
7. 修改已有文档：只接受结构化 patch；自然语言指令在无模型时返回 `PROVIDER_UNAVAILABLE`。

## 6. 文件上传限制

| 项 | 限制 |
|---|---|
| 单文件（截图/日志/视频/报告） | ≤ 32 MiB |
| 文本证据（log/stack） | ≤ 1 MiB |
| 扩展名白名单 | `.png/.jpg/.jpeg/.webp/.gif/.txt/.log/.json/.md/.mp4/.webm/.zip`（zip 仅报告，需人工确认） |
| 单实体证据数 | ≤ 50 |
| 路径 | 必须是普通文件；拒绝目录、符号链接、`..` 逃逸；规范化后必须在允许根内 |
| 命名 | 保留原扩展名，文件名清洗为 `[A-Za-z0-9._-]`，前缀 sha256 前 12 位 |
| 哈希 | sha256；同 project+subject+sha 幂等，不重复复制 |
| 病毒/宏 | 不执行、不解析 Office 宏；视频不转码（仅存原文件） |

## 6.1 可视化资产（v85）

- 用途：图片导入、Bug 截图标注、静态图；**不复用 `collab_evidence`**（那是证据系统）。
- 导入：只允许 `png/jpg/jpeg/webp/gif`；单文件 ≤ 32 MiB；普通文件；拒绝目录、符号链接与
  `..` 逃逸；复制到 `<app_data>/collab-assets/<project_id>/<sha256前12位>-<safe-name>`。
- 去重：`(project_id, sha256)` 唯一；重复导入返回既有资产，不重复复制。
- 读取：前端只能通过 `collab_asset_read(assetId)` 获取受控内容；后端校验项目归属 + 路径必须
  位于资产根目录；单次读取上限 8 MiB（超出提示分段/压缩，不一次性塞爆 WebView）。
- 引用：文档只保存 `assetId`（`va_…`）或受控相对路径；**禁止 http(s)://、data:、file:// 与任意外部 URL**。
- 归档：只改 `status=archived`，保留文件与文档引用；不物理删除。
- 标注：原始图片与标注层分离；保存只写标注 JSON，永不改写原图。
- 日志：不记录图片内容、绝对用户路径或 base64。

## 7. 网络访问限制

- 本轮**无任何出站网络请求**（无 HTTP 客户端）；Provider 未配置时明确不可用。
- 未来外部模型：只允许配置的 HTTPS 域名白名单；超时 30s；响应体 ≤ 10MB；失败不重试超过 2 次；
  不允许访问 localhost/内网（防 SSRF），除非显式配置。
- 原型/图不允许外部资源 URL；渲染不发起网络请求。
- MCP/REST 仅 loopback。

## 8. 数据隔离

- 数据库单库单用户；项目级隔离靠 `project_id` 校验，不靠前端过滤。
- 证据/资产目录按 `project_id` 分目录；跨项目路径拒绝。
- 日志：不记录证据正文、模型密钥、完整 prompt（只记长度/哈希/任务 ID）。
- 备份：新表登记 `BACKUP_TABLES`；恢复旧备份时新表为空，不阻塞启动。
- 多 Agent：同一项目共享数据；不同项目互不可见。

## 9. 操作审计

- 每次写操作一行：`entity_kind/entity_id/action/actor/actor_kind/source/revision_before/after/detail_json/created_at`。
- `detail_json` 只存变更字段名与摘要（不含正文/密钥）。
- 审计在业务事务内写入：业务失败则审计回滚；成功则不可缺。
- 保留策略：不自动清理；归档项目仍保留。
- 查询：UI 可按项目/实体分页查看；Agent 只读（`list_audit` 可选，默认不暴露给 Agent）。

## 10. 并发控制与版本冲突

- 所有更新必须 `expected_revision`；SQL `WHERE id=? AND revision=?`，`changes==0` → `CONFLICT`。
- 冲突返回：`{code:"CONFLICT", detail:"当前 revision=N"}`；调用方重读后再改，不自动合并。
- 任务拆解：事务内检查 `collab_plan_links(kind=task)` 是否已有；有则返回既有任务（幂等）。
- 版本：`UNIQUE(document_id, version)` 防并发写同版本；写入失败重试一次读最新 revision。
- 多 Agent 同时提交：各自 revision 递增，后写者冲突；审计保留双方尝试（失败也记 action=`update_rejected`）。

## 11. 大文件与大数据

| 数据 | 上限 | 行为 |
|---|---|---|
| 图节点/边 | 200 / 400 | 超限 `VALIDATION` |
| 原型页/组件 | 20 / 200 每页 | 超限 `VALIDATION` |
| 单字段文本 | 标题 200，描述 20k，方案正文 200k | 超限 `VALIDATION` |
| 复现步骤/关联文件 | 30 / 50 | 超限 `VALIDATION` |
| 证据列表 | 分页 20–100 | 不一次全查 |
| 上下文 | 每域 ≤200，scope 裁剪 | 防一次性大响应 |
| SVG 导出 | 节点 ≤200 | 超限拒绝 |
| 原型渲染 | 组件 ≤200/页 | 前端分页/懒渲染 |

## 12. 模型调用成本控制（未来启用时）

- 每次调用记录 `provider/model/prompt_tokens/completion_tokens/cost_units`（当前表有 `cost_units`）。
- 单项目日预算与单次上限（配置项）；超限 `OVERLOADED`，不自动降级为假结果。
- 图像任务并发 ≤2；文本并发 ≤4；队列上限 50；失败重试 ≤2（指数退避）。
- 相同 prompt + 参数 + 文档版本可复用结果（哈希键），避免重复计费。
- 取消：`queued` 立即取消；`running` 标记取消，结果丢弃但记录成本。

## 13. 性能目标

| 场景 | 目标 |
|---|---|
| 列表查询（1 万 Issue） | p95 < 30ms（索引命中） |
| 保存可视化（200 节点） | < 50ms（含版本快照） |
| 版本 diff（200 节点） | < 80ms |
| 原型 patch（200 组件） | < 50ms |
| 上下文读取（5 域，各 50 条） | < 80ms |
| 前端首次渲染协作视图 | < 300ms（不含 IPC） |
| 内存 | 单文档 ≤ 5MB JSON；不常驻大图 |

## 14. 失败与降级

- 数据库忙/锁：返回 `DATABASE_ERROR`，不重试写（避免重复）；读可重试一次。
- 模型不可用：`PROVIDER_UNAVAILABLE`，保留用户输入，可改本地生成或稍后重试。
- 渲染器缺失：显示「不支持的类型」+ 文档元数据，不白屏。
- 资源路径失效：证据显示「文件缺失」+ sha 元数据，不删除记录。
- 任何降级都必须可见（UI 文案/状态），不得静默成功。
