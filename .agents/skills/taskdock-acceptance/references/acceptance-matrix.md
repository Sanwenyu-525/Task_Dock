# 需求到验收的检查矩阵（按需选择）

最权威的通道和边界是仓库 `docs/ACCEPTANCE_ROUTING.md`。本页只帮助缩小任务范围，不复制其通道定义。

## 需求到证据链路（每次验收必走）

```text
用户原始需求 → 历史任务与已知问题 → 当前代码/配置 → 功能入口 → 完整业务路径
→ 成功/失败/边界 → 对应测试与本轮证据 → 四态结论 → 遗留问题
```

- 内部状态先于严重度：`UNIMPLEMENTED` / `PARTIAL` / `IMPLEMENTED_UNVERIFIED` / `AUTOMATED_VERIFIED` / `NATIVE_VERIFIED` / `DEFECT` / `ENVIRONMENT BLOCKED`。只有 `DEFECT` 才能按 P0–P3 定级；`UNIMPLEMENTED` 不自动记 Bug；`IMPLEMENTED_UNVERIFIED` 不写成通过。
- 旧问题必须确认是否真正修复：同条件复现 + 正向行为 + 至少一个边界/失败分支；历史报告、旧截图、旧测试输出不能单独作为修复证据。
- 看到 UI 入口、类型存在或测试文件存在，不等于功能实现；必须走到持久化、状态同步与失败恢复。

## 业务链路检查表（按任务挑相关链路，不要全扫）

| 链路 | 必须核对的业务点 | 失败/边界必查 |
|---|---|---|
| Agent 发现/状态/历史/跳转 | 发现入口、pipeline 有界与状态保留、历史查询、跳转目标 | 队列过载、关键状态丢失、重复事件、外部 Agent 未接入时不宣称端到端 |
| 应用扫描/搜索/添加/图标/快捷启动 | 扫描结果、搜索过滤、添加后列表/搜索/工具面板同步、图标来源 | 添加失败、重复添加、搜索与列表不一致 |
| 任务管理/提醒/规划中心 | 任务 CRUD、提醒规则、规划中心数据来源与排序 | 持久化、跨窗口同步、排序与边界、旧版本升级 |
| 智能剪贴板/图片预览/批量复制/逐项粘贴 | 采集、图片预览、批量复制、逐项粘贴入口 | 锁内不覆盖新复制、图片解码失败、第三方粘贴不代验 |
| 截图收集/文件暂存/文件夹投递（`useDropTargetsStore`、`useShelfStore`） | 拖入识别、目标文件夹、真实写入、结果报告 | 文件名冲突、权限不足、失败时保留原始文件、重复投递、目标失效/删除后的恢复、资源释放 |
| 导航自定义/隐藏/排序（`navVisibility`、`navigationRegistry`） | 可见性与排序持久化、新入口默认可见、隐藏不是删除 | 隐藏后仍轮询/订阅、重新启用重复监听、排序与持久化不一致 |
| 微件/桌面窗口/状态同步 | 微件窗口状态、主窗口与微件同步 | 隐藏/关闭后的订阅残留、跨窗口状态不一致 |
| 音频通知/语音合成/缓存 | 通知触发、语音包、缓存引用 | 缓存引用残留、音效未真实播放时不宣称系统层通过 |
| 资源清理/缓存引用/数据安全 | 清理引用计数与数据安全 | 误删用户数据、历史证据被覆盖 |
| 帮助中心/新手教程 | 条目注册、功能关联、健康检查 | 关联不存在功能、内容与实现不一致 |

**文件夹投递示例**：不能只确认设置页有“选择文件夹”按钮。须查拖入路径识别→目标目录正确→文件真实写入→同名冲突处理→权限不足错误→传输失败保留源文件→重复投递防护→目标删除/失效后的恢复→资源释放。

## 跨模块回归（只选有真实依赖的模块）

- 隐藏导航 Tab 后是否仍持续加载或轮询；隐藏功能后是否遗留事件订阅；重新启用是否产生重复监听。
- 添加应用后列表、搜索及工具面板是否同步；设置变化后是否正确持久化。
- 组件状态是否跨窗口一致；错误提示是否准确区分不同失败原因。
- 异步任务取消、恢复与异常路径是否正确；事务失败是否隔离而不污染整批。
- 共享服务回归：隐藏入口不等于销毁共享服务（见性能审计的五级判断），先判断依赖再断言泄漏。

## 原有领域定位（辅助选路径）

| 领域 | 优先核查 | 常用证明方式 | 不可替代的层 |
|---|---|---|---|
| Agent 状态/消息 | `src-tauri/src/agents/`、事件入口、pipeline、前端订阅/Store | 有界队列、状态保留、过载/取消单测；定向负载 | 真正外部 Agent 接入/多进程异常 |
| 剪贴板与图片 | `src-tauri/src/clipboard/`、`src/components/`、相关 Store | 隔离写入、回流去重、解码/粘贴定向测试 | Windows 剪贴板与第三方软件实际效果 |
| 悬浮栏/停靠 | `src-tauri` 窗口与裁剪、前端样式与拖拽 | 单元契约 + 原生区域回读 + 桌面截图 | DWM 合成和手感 |
| 通知 | `src/notifications/`、Tauri 通知命令 | 历史存储、去重与动作契约；UIA | 系统通知实际显示与点击 |
| 任务/规划 | Store、IPC、数据库迁移/备份/权限 | 类型、事务、排序/边界、回归测试 | 真实持久化与升级迁移 |
| UI 视觉/交互 | 统一 UI 原语、Token、overlay、焦点 | A/B/C 逐层，必要时 E/F | 原生窗口、真实物理操作 |
| 性能 | pipeline、IPC、订阅/计时器、资源释放 | 有条件的 A/E 采样、可复现负载 | 长驻性能平台期与真实进程资源 |

## 风险驱动的验证深度
- **低**（纯 CSS 与文案，且不含功能链路）：审查改动 + 关键状态/明暗主题截图；不默认全量 Rust 构建。
- **中**（组件状态、IPC 调用）：定向逻辑/组件测试 + 实际交互层，关注失败路径。
- **高**（迁移、剪贴板、原生窗口、并发、事件管线）：契约/集成/真机对应组合验证、隔离数据、回滚风险说明。
- **阻塞**：证据不足或环境拒绝时缩小结论范围，不为拿全绿去修改范围外代码。

## 执行前固定检查
- 仓库及子目录 `AGENTS.md`、`git status`、相关 diff。
- 相关正式文档以及源代码、测试与迁移。
- 用户原始成功标准和当前开发状态。
- 能否操作本机窗口/前台；若影响其他并行任务需要授权。
