# 需求到验收的检查矩阵（按需选择）

最权威的通道和边界是仓库 `docs/ACCEPTANCE_ROUTING.md`。本页只帮助缩小任务范围。

| 领域 | 优先核查 | 常用证明方式 | 不可替代的层 |
|---|---|---|---|
| Agent 状态/消息 | `src-tauri/src/agents/`、事件入口、pipeline、前端订阅/Store | 有界队列、状态保留、过载/取消单测；定向负载 | 真正外部 Agent 接入/多进程异常 |
| 剪贴板与图片 | `src-tauri/src/clipboard/`、`src/components/`、相关 Store | 隔离写入、回流去重、解码/粘贴定向测试 | Windows 剪贴板与第三方软件实际效果 |
| 悬浮栏/停靠 | `src-tauri` 窗口与裁剪、前端样式与拖拽 | 单元契约 + 原生区域回读 + 桌面截图 | DWM 合成和手感 |
| 通知 | `src/notifications/`、Tauri 通知命令 | 历史存储、去重与动作契约；UIA | 系统通知实际显示与点击 |
| 任务/规划 | Store、IPC、数据库迁移/备份/权限 | 类型、事务、排序/边界、回归测试 | 真实持久化与升级迁移 |
| UI 视觉/交互 | 统一 UI 原语、Token、overlay、焦点 | A/B/C 逐层，必要时 E/F | 原生窗口、真实物理操作 |
| 性能 | pipeline、IPC、订阅/计时器、资源释放 | 有条件的 A/E 采样、可复现负载 | 长驻性能平台期与真实进程资源 |

## 风险驱动的验证深度
- **低**（纯 CSS 与文案）：审查改动 + 关键状态/明暗主题截图；不默认全量 Rust 构建。
- **中**（组件状态、IPC 调用）：定向逻辑/组件测试 + 实际交互层，关注失败路径。
- **高**（迁移、剪贴板、原生窗口、并发、事件管线）：契约/集成/真机对应组合验证、隔离数据、回滚风险说明。
- **阻塞**：证据不足或环境拒绝时缩小结论范围，不为拿全绿去修改范围外代码。

## 执行前固定检查
- 仓库及子目录 `AGENTS.md`、`git status`、相关 diff。
- 相关正式文档以及源代码、测试与迁移。
- 用户原始成功标准和当前开发状态。
- 能否操作本机窗口/前台；若影响其他并行任务需要授权。
