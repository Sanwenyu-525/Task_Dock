# 性能与生命周期定向审计地图

用 `rg` 搜实际模块结构；以下路径/概念来自已有仓库规范，仍需确认当前代码。

| 症状 | 首查 | 主要风险 | 最小证据 |
|---|---|---|---|
| Agent 消息积压 | `src-tauri/src/agents/pipeline.rs`、生产者/订阅 | 无界内存、关键状态丢失、同步数据库写入 | 队列容量/退避/丢弃/溢出错误与负载记录 |
| 打开 Agent 面板卡 UI | Tauri commands、扫描/进程访问与 WebView 状态 | 同步 IO 阻塞主线程、全量扫描重复 | 调用路径、执行线程、响应耗时 |
| 剪贴板复制变慢/涨内存 | `src-tauri/src/clipboard/`、图片缓存、前端历史列表 | 大图持有、重复采集、锁竞争、无限缓存 | 采集数/体积上限、内存和退出回收 |
| 切页后渐慢 | React hooks / Zustand / event bridge | 重复订阅/轮询、unmounted 更新 | 注册/卸载计数、重复操作后请求率 |
| 窗口收起/恢复卡顿 | native window/shape/snap 命令 | 消息风暴、裁剪重算、热路径 IPC | 单次/重复几何状态与延迟 |
| 后台常驻异常 | 通知、热键、定时器、进程采样 | 持续动画/轮询、线程/句柄泄漏 | 空闲 CPU/RSS/句柄趋势与退出清理 |
| 构建导致整机卡 | npm/cargo 进程、`build-guard.mjs` | 隔离 target 膨胀、共享工作树并行竞争 | 进程归属/磁盘空间/缓存报告 |

## 隐藏模块与导航可见性（必查五级）

| 等级 | 含义 | 代码信号 | 误判风险 |
|---|---|---|---|
| L1 仅隐藏入口 | 导航渲染隐藏，共享服务继续 | `navVisibility` 可见性、`navigationRegistry` | 把隐藏当完全停用，误删共享依赖 |
| L2 暂停 UI 消费 | 停订阅/轮询/快照，后端继续 | hook 卸载、store 订阅、IPC 请求率 | 隐藏后仍高频请求误以为后端泄漏 |
| L3 停止后台采样 | 停高频采样，保留惰性/低频探测 | 定时器、探测间隔、后台线程 | 为省 CPU 砍掉必要采集 |
| L4 保持共享服务 | 多窗口/多入口共用，UI 节流/单飞 | 微件窗口、全局广播、引用计数 | 销毁共享服务导致其他窗口失效 |
| L5 完全停用 | 无其他依赖且用户明确关闭 | 功能开关 + 退出回收 | 误删仍被通知/定时任务依赖的模块 |

## 资源生命周期补充（长期运行必查）
- Agent 历史/快照、缓存增长、Tauri IPC 高频、SQLite 连接/事务、剪贴板图片缓存、截图缩略图、语音合成缓存、微件窗口、窗口关闭与退出回收、异步取消/超时/强杀后状态。
- 并行开发：先只读看 `scripts/watch-dev-processes.ps1`（scope/candidate，默认不杀）；构建缓存先 `node scripts/build-guard.mjs report`，回收仅已登记目录且默认 dry-run。不清理其他 Agent 的缓存、临时文件、正在运行的任务。

优先修根因，不用隐藏异常、强制 GC、无界重试或丢弃关键状态掩盖问题。
