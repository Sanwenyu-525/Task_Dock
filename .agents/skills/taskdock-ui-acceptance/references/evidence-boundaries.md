# UI 证据选择与边界

- **纯视觉**：优先一个代表性状态的 before/after；受双主题影响时加 light/dark；无必要不写大量日志。
- **组件交互**：须有实际 locator/mouse/keyboard 输入路径 + 状态断言；截图仅说明视觉结果。CDP 的 JS 诊断不替代用户操作。
- **窗口吸附、透明角、DPI**：需要 E 的桌面合成截图、尺寸/区域/DPI 数据；吸附感和鼠标命中再用 F。
- **系统通知/第三方复制**：不能用 WebView2 页面截图证明系统行为。
- **原生截图**：避免取入聊天、剪贴板正文、敏感路径；保持原始尺寸/比例，必要时裁剪并说明裁剪范围。
- **证据状态**：`NOT_RUN` 不冒充失败，`ENVIRONMENT BLOCKED` 不冒充通过；缺少真实系统层时结论必须缩小范围。
- **本包脚本 `check_screenshots.py`**：只检查文件是 PNG、尺寸基本合法、manifest 是否覆盖要求的主题/状态；无图像审美判断，不验证截图是否来自真机。
