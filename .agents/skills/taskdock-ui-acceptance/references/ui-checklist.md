# UI 检查矩阵

仅选择与本轮修改相关的行。规范以仓库 `AGENTS.md` 和 `docs/ACCEPTANCE_ROUTING.md` 为准。

| 部位 | 状态/边界 | 关键断言 |
|---|---|---|
| 视觉系统 | dream/liquid × light/dark × solid/glass（按需） | Token 正交、文本可读、材质强度可控、边线/圆角一致 |
| 列表、剪贴板 | 长文字、图片、滚动顶部/中间/底部、批量删除 | 无溢出/跳顶/复用错误；删除与复制反馈明确 |
| 弹窗/菜单 | hover/focus/disabled、Escape、叠层与锚点 | overlay 顺序正确、无被遮挡、无重复弹层；键盘可达 |
| 窄窗与布局 | 320/400 宽、内容很长、滚动条、DPI | 无文字裁切/控制重叠，弹窗宽度自适应 |
| 悬浮胶囊 | 左/右/上/下吸附，折叠↔展开↔取消，窗口恢复 | 正确磁吸阈值、标题栏定位、原生区域无残留 |
| 原生合成 | 黑/白/灰背景，glass/solid，激活/失焦 | DWM 像素无白边/毛边；区域回读不能代替像素 |
| 窗口集成 | Aero Snap、多显示器、缩放、恢复/退出 | 不错误触发分屏；位置和裁剪恢复正确 |
| 资源 | 动画切换、重复开关、prefers-reduced-motion | 不留事件/定时器，不产生后台持续 GPU/CPU 动画 |
| 拖拽与光标 | grab 静止 / grabbing 持续、按下/移动/释放/取消、移出窗口 | 拖拽期持续 grabbing；坐标系分层（WebView 坐标 ≠ 屏幕坐标）；命中不受覆盖层阻断；卸载后清理 |
| 信息密度 | 主面板/工具面板/胶囊/导航/微件库/设置/Agent/应用/剪贴板/暂存收集箱 | 无底部无意义空白、按钮漂移、内容挤压、卡片过大、入口不明显、固定定位遮挡、深浅不一致 |

### 最低干扰通道
A: 类型与组件测试；B: 预览 DOM/截图；C: 真实 WebView2 的 click/hover/fill；D: UIA 控件可访问性；E: 原生窗口/合成截图；F: 物理操作手感（明确授权）。

### 常见误判
- 预览正常 ≠ WebView2/真实窗口正常。
- `GetWindowRgn` 正确 ≠ 合成像素正确。
- 手动设置 React state 然后截图 ≠ 实际交互通过。
- 截图一致 ≠ 鼠标拖拽流畅、光标持续变化、通知真实到达。
- CSS 存在 `cursor: grabbing` ≠ 拖拽期持续生效；必须实际指针路径验证。
